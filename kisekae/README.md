# まじかる☆きせかえ

iPad（横画面）で遊ぶ、女の子向けの着せ替えゲーム。`index.html` 1ファイルだけで完結し、ビルド不要・外部通信ゼロ・`file://` で直接開いて動く。

## 遊び方

- 右側のタブでカテゴリを選び、アイテムをタップして着せ替える
- 「いろ▶」スワッチでアイテムごとの色替え、「かみのいろ▶」で髪色変更
- 🎲 おまかせ = ランダムコーデ / ↺ はじめから = 初期コーデに戻す
- 📷 しゃしん = コーデをPNG画像にして保存（画像を長押し）
- 女の子をタップするとジャンプする
- コーデは自動保存され、次に開いたとき復元される（localStorage）

## iPadでの開き方

1. **いちばん簡単**: 公開済みのArtifactリンクをSafariで開く（リンクは配布者から受け取る）
2. Safariでこのファイルをホストしているページを開き、共有メニューから「ホーム画面に追加」するとフルスクリーンで遊べる
3. ローカルで開く場合は `index.html` をそのままブラウザで開く（PCでも動作。マウス操作対応）

## 実装メモ

- キャラクター・服・背景はすべてこのファイル内のSVG描き下ろし（外部画像・フォント・ライブラリ不使用）
- 既存キャラクター（プリキュア等）の絵柄・名称は使用していない。オリジナルの魔法少女風デザイン
- 効果音はWeb Audioのコード生成音のみ。🔊ボタンでミュート可
- 縦持ち時は回転案内を表示（横画面専用）
