# おえかきバトル！ — personal/oekaki-battle

子供の描いた絵の写真を読み込むと、絵の特徴に合わせたステータスと技を持つキャラクターが生まれ、3対3のポケモン風バトルで遊べるゲーム。

## 位置づけ（このリポジトリの正本との関係）

- **Factory外の個人プロジェクトである**（2026-08-13、Humanのセッション内明示Commitにより「Factory外の個人依頼として実装」を選択）。
- 本リポジトリの現在のMission・戦略・実験（`OS.md` / `CURRENT_STATE.md`）とは**無関係**であり、それらを変更しない。
- `works/` のBrowser-Toy Production Route（Historical Experiment / HOLD、`DECISIONS.md` D-001）の再活性化では**ない**。`factory.yml` / `smoke.mjs` / カタログの対象外。
- 公開・deploy・カタログ掲載は行っていない（Human Gateのまま）。

## 遊び方

1. `index.html` をブラウザで開く（**ビルド不要・オフラインで動く**。スマホでもPCでもOK）
2. 「ひとりであそぶ」か「ふたりであそぶ」を選ぶ
3. 紙に描いた絵の写真を3枚選ぶ（スマホならその場でカメラ撮影も可）
4. それぞれ「なにをかいたか」を入力（例: らいおん、ドラゴン、しんかんせん）
5. キャラクター誕生 → 3対3バトル！

## ステータスの決まり方（ランダムではない）

写真はブラウザ内で画素解析され、**同じ絵＋同じ入力なら必ず同じキャラクター**になる。

| ステータス | 絵のどこを見ているか |
|---|---|
| HP | 紙に対する絵の大きさ（塗り面積）・どっしり感 |
| こうげき | 赤・オレンジ系の暖色の量、線のギザギザ度（輪郭の複雑さ） |
| ぼうぎょ | 色の濃さ、塗りの密度、左右対称性 |
| すばやさ | 細長さ、明るい色、余白の多さ（身の軽さ） |
| タイプ | 最も使われている色相（赤→ほのお、青→みず、緑→くさ…）＋描いたものの正体 |

さらに「なにをかいたか」の**モチーフ辞書**（100語超: どうぶつ・のりもの・しぜん・キャラなど）が補正をかける。かめ→ぼうぎょ上昇、うさぎ→すばやさ上昇、くじら→HP上昇、しんかんせん→すばやさ大幅上昇、など。モチーフからタイプが決まる場合は色由来のタイプと組み合わさって**2タイプ**になる。

合計値は一定の帯に正規化されるので、どんな絵でも戦える（**配分**が絵で決まる）。

## バトル

- 3対3・交代あり・タイプ相性（ばつぐん2倍 / いまひとつ0.5倍）・急所・先制技・能力ランク変化つきのターン制
- わざ4つ: モチーフ名を冠した「とくいわざ」＋タイプ技＋プロフィール由来の補助技（回復/ガード/チャージ/先制）
- ひとりであそぶ: CPUが「らくがき」を自動生成し、**同じ解析パイプライン**を通ってチームになる
- ふたりであそぶ: 1台の端末で交互に操作

## プライバシー

写真は**このページの中でだけ**処理される。外部通信は一切ない（`fetch`等不使用・単一ファイル）。保存もしない。

## 技術メモ

- 依存ゼロの単一 `index.html`（HTML/CSS/JS）。`file://` で直接開いて動く
- 画像解析: 外周画素から紙（背景）色を推定→インク画素を分離→色相ヒストグラム・塗り密度・輪郭複雑度・対称性などを抽出
- 決定性: 絵の8x8ダウンサンプルとモチーフ文字列のFNV-1aハッシュをシードにした擬似乱数（mulberry32）のみ使用
- `window.__test` にエンジン単体のテスト用フックあり（解析・キャラ生成・CPU対戦シミュレート）
