# 円相 / Ensō — 幾何学ロゴ設計室（プロトタイプ）

X で流通していた「ロゴを幾何学的にデザインしてくれる機能」（作図補助線つきの設計シート＋完成ロゴの2枚組を生成するサービス）と同型の体験を、**単一HTMLファイル・外部通信なし**で再現したプロトタイプ。

> 参照したのは公開ポストのスクリーンショットのみ。第三者サービスの名称・ロゴ・アセットは使用していない（名称はオリジナルの「円相 / Ensō」）。

## 使い方

`index.html` をブラウザで直接開く（`file://` で動作。ビルド・サーバ・APIキー不要）。

1. ブランド名を入力
2. モチーフを選ぶ（動物 / 頭文字モノグラム / 抽象マーク）
3. インク色・紙色・補助線の密度を調整
4. 「設計する」で生成。SVG / PNG でダウンロード可能

URLパラメータでも指定できる: `index.html?motif=lion&brand=Kaisei&seed=1234`

## 仕組み

- 各モチーフは**プロ品質のベジェパス（塗り重ね、painter's algorithm）**として定義されている
- 設計シートの作図円は、完成パスの輪郭を高密度サンプリングし、**円弧らしい区間へ最小二乗（Kåsa法）で円をフィットして逆算**したもの。接線・中心線・接ベクトル延長・黄金比の同心円・半径注記をシード付き乱数で選んで重ねる — 実際の「黄金比ロゴ」シートと同じ後付けの作法
- 動物モチーフのシルエットは、2名のデザイナーエージェントが競作し、レンダリング→スクリーンショット自己批評→修正のループ（8周以上）で仕上げた採用案
- モノグラムは円環（円相）＋頭文字、抽象マークは黄金角スパイラル上の円の連なりを毎回生成

## 制約・位置づけ

- 外部 API・外部フォント・外部画像・通信は一切なし（リポジトリの流儀に合わせた自己完結型）
- 本物のサービスのような自由入力からの画像生成ではなく、**内蔵モチーフ＋手続き生成**による同型体験の再現
- Historical Experiment（`works/`）とは無関係の独立プロトタイプ
