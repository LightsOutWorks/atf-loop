## P1. 文章がなぜ読まれないかの独立診断（約30分・GPT-5 Pro / 推論モデル）

**なぜChatGPT側か**: 却下された文章を書いたのはClaude。同じ主体に「なぜ悪いか」を
判定させると、自分の規則体系の中でしか見られない。実際、Claude側の仮説は2つ連続で
外れた（数値密度・漢字率、どちらも実測で分離せず）。

**ヒロの操作**: 下のプロンプトを貼り、続けて次の3つのURLを貼る。

```
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/claude/el-function-handoff-938vet/experiments/copy-2026-08-10/FINAL/note-self-analysis.md
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/claude/el-function-handoff-938vet/experiments/copy-2026-08-10/FINAL/note-tether-lock.md
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/claude/el-function-handoff-938vet/experiments/copy-2026-08-10/x-posts.md
```

```
これから、ある個人がnoteとXに公開しようとして中止になった日本語の文章を渡します。

前提として渡す情報は次の1行だけです。書き手はAIを使って業務自動化の実験をしている個人で、
読者はまだ1人もいません。文章は本人が読んで「魅力がない、変な文章も多い、自分のことだと
思えない」と判断して公開を止めました。

あなたに求めるのは、なぜそう感じられたのかの診断です。次の形式で答えてください。

【1】最初に読むのをやめる地点
各文章について、初見の読者が読むのをやめると思う箇所を1つ特定し、その直前までの原文を
そのまま引用してください。なぜそこでやめるのかを1文で。

【2】具体的な欠陥（5件以内）
原文を逐語で引用し、何が起きているかを書いてください。抽象的な講評は要りません。
「〜が足りない」ではなく「この文のここがこうなっている」の形で。

【3】書き直し
各文章の冒頭200字を、あなたなりに書き直してください。事実は変えないでください。
書き直した意図を各1文で。

【4】あなたが判断できないこと
この材料だけでは判断できないことを正直に挙げてください。

制約: 一般的な文章術（「読者目線で」「結論から書く」等）を答えに含めないでください。
この文章に固有のことだけを書いてください。
```

**検証**: 【2】の引用が原文に実在するかをヒロが1件だけ抜き取り確認する。実在しない引用が
1件でもあれば、その回答は全部捨てる。【3】は読んで良いと思うかどうかだけで判定する。

## P2. 正本の初見読み（約30分・Deep Research or 推論モデル）

**なぜChatGPT側か**: Claudeはこの正典を書いた側であり、2026-08-10 に「既に決定済みの
事項を『無い』と述べる」失敗を同一セッションで7件起こした。初見の読み手にしか見えない
矛盾がある。

**ヒロの操作**: 下のプロンプトを貼り、続けて次のURLを貼る。

```
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/main/CLAUDE.md
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/main/CONSTRAINTS.md
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/main/OS.md
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/main/DESIRES.md
https://raw.githubusercontent.com/LightsOutWorks/atf-loop/main/CURRENT_STATE.md
https://github.com/LightsOutWorks/atf-loop/tree/main/direction
```

```
ある個人事業の運用文書一式を渡します。あなたはこれを初めて読む人です。
背景説明はしません。文書だけから読み取ってください。

次の順で答えてください。

【1】この人は何をしようとしていて、今どこにいますか
文書から読み取れる範囲で。推測した箇所には「推測」と明記してください。

【2】文書どうしが矛盾している箇所
どちらが正しいかは判断しなくて構いません。食い違っている組を、両方の原文を引用して
挙げてください。件数を数えてください。

【3】書かれている計画のうち、実行された形跡が無いもの
「やると書いてあるが、やった記録が見当たらない」ものを挙げてください。

【4】この人が自分では気づいていなさそうなこと
文書全体から浮かぶもので、どの文書にも書かれていないことを挙げてください。

【5】あなたが読んで、意味が取れなかった箇所
専門用語・略語・前提の不足で分からなかった箇所を正直に挙げてください。

制約: 助言をしないでください。「〜すべき」を書かないでください。
読み取れたことと、読み取れなかったことだけを書いてください。
```

**検証**: 【2】の矛盾を Claude 側で1件ずつ照合する。実在する矛盾が1件でもあれば、
この枠は元が取れている。【4】は当たっているかどうかをヒロが判断する。
