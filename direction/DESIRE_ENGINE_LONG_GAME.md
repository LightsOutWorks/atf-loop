# DESIRE ENGINE — 長期構造と、今日植える種（2026-08-09）

Status: **DESIGN v1**（4レンズ独立構想＋統合。`DESIRE_TO_REALITY_SERVICE_DESIGN.md` の上位文書）

方法: 10x化 / 異分野移植 / 2030年からの逆算 / 非対称性発見 の4つの独立した思考を並列で走らせ、収束点を採用した。

## 0. 収束点 — 4つのうち3つが、同じ1つを最重要と判定した

> **日付を決めて、その日に戻ってきて「何が起きたか」を聞くこと。**

これだけが買えない。理由は単純で、**入力が経過時間しかない**から。

- プロンプトは数週間でコピーされ、無料で配られ、より綺麗なUIで包まれる
- 分析の質もすぐ追いつかれる
- だが「あの人が3週間後どうなったか」の記録は、**2029年に無限の資本で始めても2032年時点で3年遅れている**
- そして誰もやらない。地味で、自動化できず、デモにならず、そして決定的に——**自分の外れ率が公開記録として残るから**。顧客に「あなたを理解している」と信じてもらうことで食っている機関は、外れ率を公開できない

**2026年8月に始めるか2027年1月に始めるかの5ヶ月差は、その後この機関の生涯にわたって閉じない。**

## 1. 構造的発見（4レンズの核心）

### A. 作れる者だけが、残酷な質問をする資格を持つ

作れない世界では、人の本当のDesireを掘り起こすのは**残酷な行為**だ。掘り起こして、渡せずに、「では頑張ってください」と返すことになる。だからコーチング業界は構造的に優しくなる——**答えられない問いは傷になるので、傷にならない深さまで問いを薄める**。そして掘り起こした後の罪悪感を管理するために、伴走契約と¥38万の価格が要る。

作るコストがほぼゼロになった瞬間、この計算が反転する。**厳しい問いが安全になる。答えの直後に成果物が出せるから。**

つまり我々の側の「容赦のなさ」は性格でもブランドでもなく、**build能力によって購入されたもの**。build能力のない者には、どれだけ誠実でありたくても使えない。**誠実さは道徳ではなくアーキテクチャ。**

### B. L1無料は価格戦略ではない。独立条項（Independence Clause）である

分析でお金をもらう者は、相手に嫌がられると次が無い。だから**無意識に、徐々に、優しくなる**。彼らはsycophancyを選んだのではなく、**収益モデルが選んだ**。

我々の「L1無料・L2有償」は値付けに見えるが、実体は**対決が信じられる唯一の配置**である。資金を持つ競合はこれを模倣できない——彼らのユニットエコノミクスは顧客の満足を必要とするから。**貧しい側が防御可能なポジションを持つ、稀なケース。**

→ よってこれは価格表ではなく**憲法条項**として扱う。「分析でお金を受け取らない」を恒久ルールにする。

### C. 希少なのは「厳しい読み」ではなく、それを受け入れてもらえる立場

AIは誰に対しても、即座に、無料で、辛辣な分析を生成できる。**読み自体は希少ではない。**

希少なのは、その人が**受け入れる相手であること**。そして受け入れの源泉は2つしかない：
1. どちらの答えが真であっても金銭的利害がないこと（→ B）
2. 自分の誤りの公開記録（→ §2-5 miss rateの公開）

どちらも今すぐ始めれば安く、**後から遡って取得することは不可能**。

### D. 障壁は価格ではなく恥

L1層が動かない理由は金額ではない。**自分の行き詰まりが独自に恥ずかしいと思っている**からだ。値下げでは何も変わらない。効くのは匿名性と**集計の公開**——「N人中X%が同じだった」という正規化だけが、恥を溶かす。

→ 集計の公開（§2-3）はマーケティング施策ではなく、**L1の主要な入口機構**。

## 2. 今日から積む5つ（すべて限界費用ゼロ）

### 2-1. Direction Card と、日付の約束 ★最優先

全セッションの最後に1枚: **アンチビジョン / 反証可能な仮説1つ / 最小の検証行動 / 本人が決めた日付**。控えを取る。その日に一度だけ連絡する——「やりましたか。何が起きましたか」。**オファーを付けない。**

記録は4項目のみ: 選んだ方向 / 日付 / 実行したか / 実際に何が起きたか。

これは同時に4つの問題を解く: ①一回性の成果物を関係に変える（棄却した自動課金なしで）②競合が絶対に публишしない誠実な成果証明を作る ③有償の会話が「営業の時」ではなく「詰まった時」に発生する ④コーパス・prior・アーカイブの原料になる

### 2-2. 構造化された返信フォーマット ★時限あり

記事に9項目の記入枠を置く（実装済み）。自由記述で50件集まると比較も集計も公開もできない**50個の物語**になる。構造化されていれば**分布を持つデータセット**になる。

**これは公開前にしかできない。** Batch 1で送信20件のjoin keysを失い、20枠が永久に分析不能になった前例が既にrepoにある。同じ失敗をNを増やして繰り返すことになる。

### 2-3. 集計の公開（Desire Mortality Table）

個別の事例ではなく**集計だけ**を公開する。「この手順を実行したN人のうち、X%は掲げていた目標が自分で選んだものではなく、親か雇い主から受け継いだものだった」。

n=1から公開し、更新閾値を明示する（「n=10で更新します」）。**見えている不完全なカウンターが募集機構そのもの**（Kickstarterの温度計、Wikipediaのスタブと同じ物理）。

### 2-4. 断った記録（今日も金を取らなかった）

無料または既存の解決策へ流したものを、**実際のツール名と理由つきで公開ログにする**。

競合はこれを書けない——「その無料ツールで解決します」は彼らの収益そのものだから。我々は収益を**残余**（既存では解けないもの）に置いているので、彼らを破産させる一文が我々には無料。**純粋なcounter-positioning。**

### 2-5. 殺した記録を先に公開する

新規に書くものはゼロ。既にrepoにある材料だけで1本になる: AIが俺の一番好きな事業案を凍結した判定文 / founder projectionの指摘 / SENT 20 → REPLY 0 / 全チェックPASSで遊べなかったゲーム。

**飽和したAI生成コンテンツの世界で、残された唯一のコストのかかる誠実さの信号は、検証可能な自己不利益の開示。** 投資家・リテンションモデル・コーチング業界のコスト構造を持つ競合には、これが模倣できない。

## 3.5. 【最重要・確定】核は在重力営業だった

2026-08-09、ヒロが在重力営業の思想正本（113章）を提示。**照合の結果、Desire Engineは新規事業ではなく、在重力営業の適用範囲を「経営者」から「個人」へ広げたものだと確定した。**

ヒロ自身が既に §63 で接続を書いていた:

> Factory: Human Desireを最良のCapabilityでRealityへ。
> 営業: 経営者のDesireを理解し、選択肢を整理し、本人がRealityへ変える。
> 共通: Toolから始めない / 商品から始めない / **Desireから始める** / 最良手段は後から選ぶ / Human Commitを残す / Realityが答える

### この照合が解いた最大の急所

E-012評価が指摘した未解決の急所は「**プロンプトそのものは商品にならない**」だった。v0.1はMom Test＋Whiston 2017＋反sycophancyプロンプト——**全部公開知識**で、誰でも明日コピーできた。

**在重力営業がその欠落を埋める。** これは高額・不可逆・一生に一度の意思決定の現場で、数億円の歪みインセンティブを持つ語り手を相手に、数年かけて鍛えられた聞き取り作法であり、**書籍にもメソッドにも存在しない**。

### そしてv0.1の設計は在重力違反だった（重大な修正）

v0.1の「敵対的レビューで本人が認めたくない仮説を突きつける」は、在重力の以下に違反する:

- §3.5 心理を直接言い当てない（「心理は配慮のために使い、断定のために使わない」）
- §42 Heart Reader（内部では見てよい。**返す時は事実・構造・選択肢へ変換する**）
- §12 補完禁止

→ **プロトコルをv1.0へ全面改訂した**。矛盾は検出するが原因は指定しない。「Aと言っている。同時にBという行動がある」という**事実の並置**まで。原因を決めるのは本人。

**そしてこの形の方が実は効く**——人は診断されると防御するが、自分の行動記録を並べられると考え始める。在重力の「裁かないことが最も深く届く」という発見が、そのまま自己分析にも成立する。

## 4. ヒロ固有の非対称性（誰にも模倣できない唯一の入力）

現行プロトコルはMom Test＋Whiston 2017＋反sycophancyプロンプトで構成されており、**全部が公開知識**＝誰でも明日コピーできる。E-012の評価が指摘した未解決の急所（「プロンプトそのものは商品にならない」）はここ。

**欠けている固有入力は、M&A承継面談の質問セット。**

これはどのコーチング手法よりも過酷な条件下で鍛えられている——自己物語を歪める動機が数億円ぶんある売り手と、その語りを信じると商業的に罰せられる仲介者。**人の自己申告を職業的に疑うこと**は、まさにsycophancy問題の解であり、ヒロには金銭を伴う反復訓練が数年ぶんある。

- 実行: 30分・オフライン・ツール不要。**初回承継面談で実際に聞く10の質問**と、**経営者が最も黙り込む3つの質問**を記憶から書き出す。ビジネス名詞を全部剥がす。それが個人向けの質問セットになる
- これが埋まると: 模倣不能な聞き取り装置 / 引用可能な手法名 / 記事に載せる唯一のコピー不能な主張 / 予算を持つ唯一のセグメント（経営者）への正当な入口

## 5. 恒久ルール（憲法級・drift防止）

- **分析でお金を受け取らない**（Independence Clause。§1-B）
- **レビュー側を収益シグナルから構造的に隔離する**——「有料顧客と話している」と分かった瞬間、AIも人間もsycophantになる。2030年に残る機関は最良のモデルを持つ機関ではなく、**4年かけて「同意することで報酬を得ない」配置を作った機関**
- **外れ率を公開し続ける**（§2-5）
- **1で解けるものに2や3を売らない**（§2-4）
