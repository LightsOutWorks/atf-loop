## 1. DM移行の3ゲート（どれか1つ通過するまでDMしない）

(a) 相手が公開投稿で明確に困りごと・募集を発信した（この場合は即DM可）
(b) 本物のリプ往復が2回以上あった
(c) 相手がこちらのコンテンツに2回反応した

どれも未達なら公開リプ・いいねで温め続ける（JP相場: 2〜4週間）。

**Permission Bridge（推奨・最強の型）**: DMの前に公開リプで許可を取る——「この件、リプだと長くなるので、よければDMで少し詳しくお伝えしてもいいですか？」。不意打ち性が消え（晒し・スパム認定・将来の規制リスクを同時に回避）、相手が承諾すればMessage Requests問題（後述）も解決する。

## 2. 初回DMの型（JP・2〜4行・リンクなし・価格なし）

> はじめまして、（リプ失礼しました）◯◯です。さきほどの△△のご投稿の件、実は同じ課題を□□で解決したことがあり、もう少し具体的にお伝えできそうだと思いDMしました。今どの部分が一番ネックになっていますか？

構造: 挨拶＋名乗り / 投稿参照（どこで知ったか） / 根拠1行 / 質問1つ。です・ます敬語（尊敬語過剰は不要）。

**アンチブロック鉄則**: 初手売り込み禁止 / 初手タメ口禁止 / メッセージ1-2通目に外部リンク・LINE誘導禁止（2025年のスパム波以降、詐欺パターン認定される）/ 「素敵な投稿ですね！」単体の定型褒め禁止 / リプを無視した相手にDMしない / **全DMは晒される前提で書く——公開できない文は送らない**。

## 3. 一問一答ラダー（Pain発見。1メッセージ1質問・順番に・買いシグナルが出たら即中断）

①「それ、最後に起きたのっていつでした？」（過去の実例に錨を下ろす）
②「そのとき実際どう対処されたんですか？」（**回避行動テスト——最強の1問**。何か試した=本物のPain）
③「それって月どのくらい起きてます？」（頻度）
④「その度にどのくらい時間/お金が溶けてる感じですか？」（コスト）
⑤「放置するとどうなっちゃうんですか？」（緊急度）
⑥「他に試したことってあります？」（投資度）

**禁じ手**: 「こういうサービスあったら使います？」（仮定の質問は全部ゴミデータ）。

**ゴミデータの往なし方**: 褒め言葉→「ありがとうございます。ちなみに今って◯◯どうやって回してます？」/ 「絶対買います」→「直近でそれが起きた時のこと、具体的に聞いてもいいですか？」/ 機能要望→「それがあると何ができるようになるんですか？」

**送信前3チェック**: ①相手の生活の話か（自分のサービスの話になってないか）②過去の具体的事実を聞いているか③1質問・3文以内（約50-120字）か。

## 4. Painスコアカード（頭の中で採点・各0-2点）

頻度（週1以上=2）/ コストの定量化（金額or時間を自分で言った=2）/ 緊急度（期限・外圧あり=2）/ 回避行動（何か試した=2、「何もしてない」=0）/ 決裁権（本人が決められる=2）

- **6点以上 → §5のBridgeへ**
- 3-5点 → もう1周だけ掘る
- 2点以下 → 友好的に終える。オファーしない（audience扱いに降格）

**即時撤退シグナル**（2つ揃ったら投資停止）: 愚痴を楽しんでいるが実害を言えない / 一度も何も試していない / 「あったらいいな」枠 / 具体的な話（時間・価格）になると急に曖昧になる / 全部カスタム無料希望 / 価格感覚が10倍ズレ。

**ゾンビ処理**: 「また連絡します」=柔らかい拒絶。7日後に有益情報1回だけ（askなし）→無反応なら「合わなそうならスルーで大丈夫です。◯◯で詰まったらいつでもどうぞ」で正直にクローズ。3度目の追撃は絶対しない。

## 5. Bridge（Pain確認→オファー。スコア6+または買いシグナル時のみ）

1. **ミラー**: 「◯◯のせいで毎週×時間消えてる、って話でしたよね」
2. **許可（BYAF=断る自由を明示）**: 「それ、実は仕事でよく直してるやつなんですが、もしよければ直し方のたたき台作りましょうか？要らなければ全然スルーでOKです」
3. **YESが来てから、正直なマイクロオファー**: 価格を先に明示・偽の緊急性なし・出口明示

**買いシグナル優先則**: 相手が価格・実現性・納期を聞いてきた瞬間、残りの質問を捨てて即答（最速回答者が勝つ）。次の最小ステップを1つだけ添える。

## 6. クロージング（提案書を作らない・3行スコープ）

> ありがとうございます。でしたらまず小さく始めましょう。
> ①やること: ◯◯の診断＋改善案3点（A4一枚のメモで納品）
> ②期間: 着手から◯営業日
> ③料金: ¥◯◯,◯◯◯（前払い）
> これでよければ「OK」と返信ください。決済のご案内をお送りします。
> ※含まれないこと: 実装作業・継続相談（必要なら別途お見積り）

**価格ラダー**: 入口=有償診断 **¥5,000-15,000**（60-90分作業＋A4一枚所見＋追加質問1往復まで）→ 本命=Pilot **¥30,000-50,000**。

**診断の訴求軸（2026-08-09 Hiro仮説を反映）**: 売るのは「AIのやり方」ではなく「**あなたの状況で何から着手すべきかの発見**」。能力が無料化する時代の希少資源は方向性——「何でもできるが何をすべきか分からない」が最大のPain源という仮説に基づき、診断は常に**優先順位付きの3点**（何を・なぜその順で・最初の一歩）を納品物の核にする。仮説の検証は§9の3タグ分類で行う。診断料は「Pilotに進む場合は全額充当」と明言（値引きでなく前進インセンティブ）。**診断を無料にしない**——無料は相手の本気度を測れず、こちらの時間も守れない（そう説明してよい）。

**異議処理**:
- 「検討します」→「ご判断の材料として、いちばん引っかかっているのは費用・内容・タイミングのどれに近いですか？」→1点だけ解消→期日を合意して1回だけフォロー。偽の締切は使わない
- 「高い」→ 値引きせずスコープを縮める:「金額は下げられないのですが、ご予算¥◯◯なら範囲をここまで絞る形ならお受けできます。見送っていただいても全く問題ありません」

**スコープ防衛**: 着手前に「修正2回まで。追加要望は都度見積り・承認後着手」を必ず書く。1回でも無償対応すると恒常化する（時給500円化の実例あり）。**¥10,000超は前払い必須**——「入金確認後の着手とさせて頂いています。お互い最短で確定します」。断られたらそれが判定材料。

## 9. Funnel記録（1接触ごと・LEDGER拡張）

`元投稿URL → 公開往復数 → DM送信日 → 既読? → 返信? → オファー前往復数 → オファー提示? → 成約?` を記録。

**Painの3タグ分類（Hiro仮説 2026-08-09の検証装置）**: Pain会話が成立するたびに、根本のギャップを1つタグ付けする——
- `HOW-gap`: やり方が分からない（能力・知識の不足）
- `TIME-gap`: 何をやるかは分かっているが手が回らない（実行の不足）
- `WHAT-gap`: **そもそも何をやるべきか分からない**（方向性の不足）

仮説: AI普及に伴いWHAT-gapの比率が増える。10会話ごとに比率を集計し、WHAT-gapが優勢なら商品設計・訴求・記事テーマをdirection-discovery側へ寄せる。参照バンド: 文脈個別化DMの返信率20-35%（汎用は2-4%）/ 同時15-20人の温めで月1-2件の live会話 / JP実例 100DM→15返信→3成約。
