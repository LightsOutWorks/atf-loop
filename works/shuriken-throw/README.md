# 手裏剣 — SHURIKEN NIGHT

迫ってくる敵に手裏剣を投げる、単一HTMLファイルのブラウザゲーム。iPhone（縦持ち・タッチ操作）を前提に作ってある。

`index.html` を開くだけで動く。ビルド・サーバ・外部通信は一切不要（`file://` でも動作する）。

## 遊び方

| | |
|---|---|
| **投げる** | 画面のどこでもタップ。押しっぱなしで連射、指をずらすと狙いが変わる |
| **狙い** | 指の近くにいる敵へ自動で吸い付く（スマホ前提の照準補助）。頭を狙うと2倍ダメージ＋得点1.5倍 |
| **手裏剣** | 手持ち8枚。撃つと減り、自動で少しずつ戻る。空撃ちは出ない |
| **体力** | 3。敵に接近されるか苦無を受けると減る |
| **得点** | 敵の種類 × 遠さ（遠いほど最大2倍）× 連撃倍率（5連ごとに+1、最大×8）。連撃は被弾か2.6秒の無得点で切れる |

### 敵

| 敵 | 特徴 |
|---|---|
| 走忍 | 基本。1発 |
| 韋駄天 | 速く、左右に大きく振れる |
| 鎧武者 | 3発必要。兜のせいで頭部ボーナスが無い |
| 大盾 | 盾を上げている間は完全に弾く。**盾を下ろした瞬間だけ通る**（下ろしている間は突進が速い） |
| 苦無 | 中距離で止まり、苦無を投げてくる。苦無は撃ち落とせる（+80） |
| 大鬼 | 5陣ごとのボス。**額の光点に当てると3倍ダメージ**。金棒を投げてくる |

### 巻物（撃つと取得）

`連` 連射強化 ／ `三` 三連投げ ／ `静` 敵を減速 ／ `癒` 体力回復

## iPhone向けにやっていること

- `viewport-fit=cover` ＋ `env(safe-area-inset-*)` で、ノッチとホームインジケータを避けてHUDを置く
- `visualViewport` のサイズを実測して毎回レイアウトし直す（Safariのツールバー開閉・回転に追従）
- ピンチズーム・ダブルタップズーム・ラバーバンドスクロールを全部止める（`touch-action:none` ＋ `gesturestart` 抑止 ＋ `touchmove` の `preventDefault`）
- `devicePixelRatio` を2で頭打ちにする（3x端末で描画量が2.25倍になるのを避ける）
- マルチタッチ対応（複数指でも取りこぼさない）
- 背景は解像度変更時に一度だけオフスクリーンに描いて以後は転送するだけ。毎フレームの `shadowBlur` は使わない
- ホーム画面に追加したときのフルスクリーン表示（`apple-mobile-web-app-capable`）
- 音はWebAudioのコード生成のみ。最初のタップでAudioContextを解除する
  - **iOSはマナーモード中WebAudioを鳴らさない。** 無音のときは端末側の消音を解除する

## 実装メモ

- **投影** — 奥行き `z` の一点透視。`焦点距離 = min(幅×1.35, 高さ×0.62)`、カメラ高 `3.0`、`z=2.6`（＝敵が到達する距離）がちょうど画面下端に来るように決めてある。これで奥行き帯が画面の縦方向に実際に広がる
- **レーンの収束** — 敵は近づくほど中央に寄る。画面外に逃げた敵に「当てられないのに殴られる」状況を作らないため
- **当たり判定** — 敵ごとに頭・胴の球を持ち、手裏剣は毎フレーム3分割して球と判定する（高速移動のすり抜け防止）。タップ時に狙いを1つロックし、飛翔中は緩く追尾する
- **描画順** — 敵・手裏剣・苦無・巻物・花びらを毎フレーム `z` でソートして奥から描く

## 検証

DOMシムではなく実Chromiumで、iPhone相当のビューポートと実タッチイベントを使って確認している。

```
npm i -D playwright && npx playwright install chromium
node works/shuriken-throw/verify.mjs
```

確認項目は `verify.mjs` 冒頭のコメントに列挙してある（ロード／スクロール抑止／canvas解像度／開始・命中・頭部狙い・長押し連射・休止・終了・再挑戦・最高得点の保存／横持ち・小画面・途中回転／高負荷と100秒連続プレイでのフレームレートと例外・リーク）。

計測値（Chromium・393×852・DPR2）: 敵42体同時で61fps、100秒連続プレイ後も61fps・ヒープ10MB・例外0。

### 補足: プレイヤー向けテキストを日本語にした理由
