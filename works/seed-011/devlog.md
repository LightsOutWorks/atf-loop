# devlog — seed-011

## 作品名
MAGNET TIDE

## テーマ選定理由(既存作品との差別化)
ATF IDEA FUNNEL のフェーズ1〜3で12候補を生成・統合・採点した結果、上位3(TRIAGE PULSE / STACK BALANCE / POLARITY FLIP)から POLARITY FLIP を選んだ。

seed-001〜010 は「照準や選択で1つの対象を直接狙って解決する」系統(NEON RANGE の射撃、SIGNAL PURGE の識別駆除、EMBER CANOPY のピーク捕獲、FROST HARPOON の先読み照準、VOLT CACHE のクリック破壊、PRISM SPLIT の再帰分割など)や、「1つの対象に対する保持・タイミング判断」系統(BEACON WATCH / STRATA WARDEN のタイミング解放、METEOR CHARGE のチャージ量調整、TETHER LOCK のホールド我慢比べ)にほぼ収まっており、いずれも「入力=特定の1対象への働きかけ」という構造を共有している。

POLARITY FLIP(MAGNET TIDE)はタップが特定の対象を狙わず、画面全体の場の極性そのものを切り替えるグローバルな状態トグルであり、1回の入力が画面上の全オーブの挙動(引力/斥力の向き)を同時に反転させる。この「対象選択ではなく場の状態を操作する」という入力構造は既存作品のどれとも異なり(C1)、かつ反転の結果が即座に視覚化される(全オーブの動きが一斉に変わる)ため理解とフィードバックの速さ(C2/C6)も両立できると判断した。

## 主な設計判断
- 極性は2値(A/B)のみとし、色(シアン/マゼンタ)で即座に区別できるようにした。タップ1回=極性反転という単純な入力に絞ることで、操作の理解に必要な試行回数を最小化した(C5)。
- 極性が一致するオーブは中心のコレクターへ強く引かれ、一致しないオーブは弱く弾かれる設計とし、さらに極性に関係なく働く弱い求心ドリフトを加えた。これにより「正しいタイミングで反転すれば早く安全に回収できる」という戦略的判断を残しつつ、無作為なタップの連打でも捕獲がゼロにはならない設計にして安定性を確保した。
- streak(連続捕獲)によるスコア倍率(最大4倍)を導入し、極性ミスで弾かれたオーブを1つ失うとstreakがリセットされる仕組みにした。これによりプレイに慣れるほど「連続捕獲を守るために反転タイミングをより慎重に選ぶ」という新しい判断が生まれるようにした(C7)。
- 状態遷移・検証フックは smoke.mjs の契約に厳密に合わせ、時間管理は performance.now() と requestAnimationFrame のみで行い、Date.now() / setInterval には依存していない。
- window.__GAME__.checkSuccess() は「タップ操作の結果としてオーブを1個でも実際に捕獲したか」(capturedCount >= 1)を返す実装とし、ハンドラ呼び出しの有無だけを見るような偽装的な実装は避けた。
