# research/INDEX.md — 問いから引く索引

## 使い方

1. **何かを主張する前に引く。** 「〜だから〜すべき」と書く直前に、その問いをここでgrepする。
2. **調査を始める前に引く。** 「調べていない」と言う前に、ここに答えがあるか見る。既に棄却済みの案を新発見として出さないため。
3. grep例: `grep -i "漢字率" research/INDEX.md` / `grep "反証済み" research/INDEX.md` / `grep "矛盾" research/INDEX.md`
4. **状態が `反証済み` の行は、否定された内容ごと残してある。** 消すと同じ道に戻るから残している。結論欄ではなく状態欄を先に読め。
5. 生ファイル（`research/raw/wf_*.txt`）を直接引用して判断根拠にしない。必ずこの索引を経由する。

## 凡例

**状態**（この索引の判定）

| 値 | 意味 |
|---|---|
| `有効` | 反証されておらず、根拠も十分。そのまま使える |
| `反証済み` | 後の実測・裁定で否定された。何によって否定されたかを結論欄に書く。**再提案するな** |
| `未検証` | 主張はあるが検証されていない。使うなら「未検証」と明記して使う |
| `範囲限定` | 特定条件下でのみ成立。条件を結論欄に書く |
| `矛盾` | 複数の抽出が食い違う。**両方の数値を残してある**。どちらかを黙って採るな |

**強さ**（元調査の自己申告）: `実測`（本ワークフロー内で自分で計測）/ `一次情報`（原資料に直接到達）/ `二次情報`（解説・スニペット経由）/ `推論のみ`（測定なし）

**反証照合に使った文書**（この索引より上位。食い違ったらこちらが勝つ）

- `direction/WRITING_SYSTEM_JA_FALSIFICATION_2026-08-10.md` — 日本語書法 C23ゲート1〜3を**停止**（調整ではなく停止）
- `direction/WRITING_SYSTEM_EN_AUDIT_2026-08.md` — 英語規則12本削除 / 2本逆転 / 11箇所訂正
- `direction/COCONALA_VERDICT_2026-08.md` — VERDICT: HOLD_WITH_TRIGGER（通常サービス出品は KILL）
- `CURRENT_STATE.md` — 実測の現状（note記事0本 / Xフォロワー3 / 確定収益 JPY 0 / EN_GATE）
- `experiments/INDEX.md` — 実験の採番（E-001〜E-013）
