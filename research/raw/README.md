## なぜあるか

2026-08-10、同じ日に3回、既に出ていた調査結果を引き出せずに誤った主張をした。

1. C-1/C-2実投稿の7軸差分（`experiments/md2-distribution/CANARY_2026-08-08_CONTENT_CANDIDATES.md`）が「次のX投稿に使う」で範囲を止めており、note記事・bio・書法へ渡らなかった
2. 漢字率20〜30%は `direction/WRITING_SYSTEM_JA_2026-08.md` 1472行で既に棄却済みだったのに、新発見として提案した
3. 日本語書法の調査記録を探して**英語版のworkflow記録を開き**、「日本語の文章を1本も読んでいない」と誤って報告した（実際は日本語検索169件・実在の書き手19人以上を名指しで調査していた）

いずれも「調査は存在するが引き出せない」。原因は、成果が15個の不透明なID（`wf_*`）の下にあり、しかも**リポジトリ外（コンテナ内）にしか無かった**こと。コンテナは非活動で回収されるため、放置すれば全消滅する。

各ファイルは1回のworkflow実行における全エージェントの**最終返り値**を連結したもの。`===== AGENT =====` で区切られる。合計126エージェント / 約1,732,000字。

会話の全文（ツール呼出・思考）は含まない。それらは `~/.claude/projects/.../subagents/workflows/` にあるが、コンテナと共に消える。

## 扱いの注意

**ここに書かれていることは検証済みではない。** 後から反証された主張がそのまま残っている（例: 日本語書法のゲート1〜3は `direction/WRITING_SYSTEM_JA_FALSIFICATION_2026-08-10.md` で停止済み）。

**引くときは必ず `research/INDEX.md` を経由する。** 索引が各項目に「有効／反証済み／未検証」を付ける。生ファイルを直接引用して判断の根拠にしない。
