### 確定した禁止語（本節から得られた唯一の実signal）

ヒロの指摘: **「付き合っていますは上からすぎて最悪です」**（AIが書いたnote自己紹介案に対して）。

「〜に付き合う」は、**その活動が相手のものであり、こちらが時間を分け与えている**という位置関係を作る。相手が欠いていて、こちらが持っている、という構図。

**やりたいことが分からない状態には既に恥が伴っている**（`direction/DESIRE_ENGINE_LONG_GAME.md` 構造的発見D「障壁は価格でなく恥」）。そこへ「付き合っています」を置くと、**相手に「自分は負担をかけている」という感覚を確定させる。** 在重力の「相手の判断を奪わない」をコピーの語彙レベルで破る。

**以後、全ての公開コピーで使用禁止:**

| 禁止語 | 理由 |
|---|---|
| 付き合う / 付き合ってあげる | 相手の活動に時間を分け与える構図 |
| 寄り添う | 優しく聞こえるが位置は上のまま。この界隈で多用されるため特に警戒 |
| サポートする / 支援する | 主体が相手、補助がこちら、という上下 |
| 導く / 引き出す / 気づかせる | こちらが答えを持っている前提 |
| 教える / アドバイスする | 同上 |
| 〜してあげる系すべて | — |

**代わりに: 役割を説明しない。** 「私は何をしてあげる人か」を書かず、**事実だけ置く**（何があるか / 何が起きるか / いくらか）。これは在重力の「現実を一つ置く。説得しない」のコピー版である。
