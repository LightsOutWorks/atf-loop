## 2026年8月2日、遊び終わってもLOCKEDとRELEASEDが0のままでした。

公開してあるTETHER LOCK（seed-009）を自分で遊んだら、何度やってもスコアが0のまま終わりました。終了画面から書き写した記録はこれです。

```

期限切れになったドリフター（画面を流れる、ロックの相手）は66体あるので、進行そのものは動いています。ロックの回数を数えるLOCKEDと、解除の回数を数えるRELEASEDだけが、そろって0でした。

## beginHold()を呼ぶ2箇所は、どちらもマウスとタッチから届いていませんでした。

コードを開くと、holdingをtrueにするbeginHold()の呼び出しは2箇所しかありません。1つ目はhandleAim()の中にあって、index.htmlの320行目から始まる4行に阻まれています。

```
if (!holding){
  engagedId = idx === -1 ? -1 : targets[idx].id;
  return;
}
```

すでにロック中でないと、その先へ進みません。進行中のロックの相手を変えることはできて、開始だけができませんでした。

2つ目のconfirmDown()は、keydownのSpaceとEnterからしか呼ばれていません。だからポインタ入力、つまりマウスとタッチではロックを開始できず、物理キーボードだけが動いていました。

解除側のcancelHold()も同じ条件で無音のまま空振りするので、RELEASEDも0のままです。LOSTだけが66まで増えたのは、期限切れの判定が入力と関係なく走っているからです。

タッチ固有でもiOS固有でもありませんでした。touchstartとtouchmoveは無くて、ポインタイベントに統一されています。

マウスとタッチで処理を分ける分岐も入っていません。タッチが止まる原因になりやすい設定を3つ見ました。passiveとpreventDefaultとtouch-actionで、どれも正常でした。
