**「FXで勝ちたい」を否定しない。** 提供側の規律「決めつけない・裁かない」（`SELF_ANALYSIS_PROTOCOL.md` §331）どおり、FXが本人にとって正しい手段である可能性を実験の設計段階で排除しない。排除するのは**提供側が金融の中身へ踏み込むこと**だけである。

## 3. 判定

### 判定点（起点事象を明示 — 検査項目3）

**起点事象 = Direction Cardの返却**。実施日ではない（ワークの実施はHuman Gateであり、いつ実施されるかは契約時点で `UNKNOWN`）。

> **判定点 = 本人が設定した検証日。ただし返却から45日を超える場合は、45日時点で `VOID`（判定窓超過）とする。**

### verdict（全語彙に成立条件を定義 — 検査項目2）

| verdict | 成立条件 |
|---|---|
| **PASS** | (a)実行 または (b)明示的な書き換え が観測され、**かつ** Direction Card の L0–L2 に本人の言葉で書かれた項目が1つ以上ある（＝手段の層から動いた証拠） |
| **FAIL** | カード返却済みで判定点に到達し、**(a)(b)いずれも観測されない**（＝本人が決めた保留ですらない無反応。L0–L2の埋まりは問わない） |
| **VOID** | ワーク未実施 / 途中中断 / 同意が得られず記録なし / 判定点に本人と接触できず / §6 KILL条件の発火による中止 / 判定窓超過。**`VOID` を `FAIL` として学習しない**（`CONSTRAINTS.md` Part I §6） |
| **STALE** | 判定点前に上位正本（戦略・Boundary・`SELF_ANALYSIS_PROTOCOL.md` v1.0）が変わり、比較が無効になった場合 |

**中間状態を定義する**: (a)または(b)は観測されたが、L0–L2 が全て空欄だった場合。これは「一歩は動いたが、手段の層から目的の層へは動かなかった」を意味し、hypothesisの前半だけが外れた状態である。**`PARTIAL` と記録し、PASSにもFAILにも寄せない。** `PARTIAL` に下流の決定（有償化・横展開・E-012のstatus変更）を一切紐づけない（検査項目2: 未定義verdict語へ下流決定を紐づけない／検査項目6: 判定のために推測で確定させない）。

FAIL条件からL0–L2の埋まりを外したのは、AND結合ではFAILがほぼ成立せず、仮説が反証されない設計になるためである（`CONSTRAINTS.md` Part I §6）。**無反応は単独でFAILとする。**

verdict確定後の記録は `OS.md` HI-5 の語彙（`GO` / `HOLD` / `KILL` / `WAIT` / `NO_ACTION`）で行う。

## 5. 非目標（Non-goals）

### 5-a. 金融・投資に関する助言のすべて

**本実験は金融・投資の助言を一切含まない。** 提供側は次に踏み込まない。

- 相場観 / 価格予測 / 売買タイミング / 通貨ペアの選定
- レバレッジ / ロット / 資金配分 / 損切り幅 / 目標利益
- 手法・インジケータ・EA・シグナル・自動売買の**評価も生成も**しない
- バックテスト・検証環境・分析ツールの実装
- **「FXを続けるべき / やめるべき」を提供側から表明すること**

根拠は2つ。**(1) 法令**（`CONSTRAINTS.md` Part I §1）——FXは金融商品取引法上のデリバティブ取引であり、投資助言・代理業は登録制。無償・1対1であっても、Factoryの実験として反復・商品化の意図を持つ設計にすると業性の側へ寄る。**(2) 規制領域Non-goal**（`direction/DESIRE_TO_REALITY_SERVICE_DESIGN.md` §4-a）——「誤りが第三者の権利・事業・**金銭**へ重大な影響を与える成果物」は現在フェーズのNon-goal。**単なる免責文では解除できない。**

**扱うのは「その人が何を得たくてFXという手段を選んだか」の構造だけである。** Direction Cardに金融商品・取引に関する記述を載せない。

これは `CURRENT_STATE.md` §7-0-a の「就労選択支援の指定申請書式パック = `KILL`（規制領域参入）」と同型の処理であり、新しい判断ではない。

## 6. KILL条件（実験の即時中止）

次のいずれかが観測された時点で中止する。中止時のverdictは `VOID`。

1. 本人が嫌がった / 同意を撤回した
2. **本実験の過程で本人の入金・増額・新規取引が行われた、または提供側の関与がそれを促した兆候があった**
3. **生活に影響する損失・借入・依存の兆候が判明した**
4. 提供側が §5-a の線を越えた（Failure Mode発火）
5. Humanの中止裁定

**3が発火した場合の処理**（Hard Boundary側の処理であり、実験の都合を優先しない — `CONSTRAINTS.md` Part I §1「人間の尊厳」「重大な実害」）:

> ワークを中止し、**公的な相談窓口が存在することだけを伝えて終える**（消費生活センター / 精神保健福祉センター / 日本貸金業協会の貸金業相談・紛争解決センター等）。提供側が返済計画・資金繰り・依存の評価に踏み込まない。実験の記録より本人の安全を優先し、**この場合は記録を残さない。**
