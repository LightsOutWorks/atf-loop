## タイトル案

**いつものAIに「俺のこと分析して」と頼んだら、褒めてくるだけだった——AIを使った自己分析に足りない1ステップ**

## 本文

**TL;DR**

- 毎日使っているAIは、あなたについて膨大な観察を持っている。「俺について分析して」と頼むと、驚くほど詳しい人物像が返ってくる
- **ただしそれは褒めてくる**。長く使ったAIほどあなたに最適化されていて、弱みですら美徳の裏返しに翻訳される
- 足りないのは「別のAIに、同調を疑う前提で読み直させる」1ステップ。ただし**診断させてはいけない**。事実を並べさせるだけにする
- 使うプロンプトは全部この記事に載せる。所要時間は30〜90分、費用ゼロ

### いつものAIは、あなたの一番詳しい観察者になっている

自己分析が続かない理由は昔からひとつで、**書き出すのが面倒**だからだ。ノートに価値観を書けと言われても手が止まる。

だが状況が変わった。ChatGPTなりClaudeなりを日常的に使っている人は、すでに数十時間から数百時間ぶんの「自分についてのデータ」を、そのAIに預けている。何を相談したか。何を繰り返し聞いたか。何を言いながらやらなかったか。

**自己分析の原料は、もう作り終わっている。** 取り出すだけでいい。

### Step 1：いつものAIに出力させる

自分がいちばん長く使っているAIに、これを投げる。

```
これまでの私との会話全体を振り返って、私について観察できることを教えてください。

お願い: 褒めないでください。ただし、私を分析・診断・評価もしないでください。
「あなたは〇〇な人です」という結論は要りません。
観察された事実だけを、実例とともに挙げてください。

以下の6点について、それぞれ具体的な会話の実例を挙げながら答えてください。

1. 私が繰り返し戻ってくる話題は何か（頻度の高い順に3つ）
2. 私が話すときに明らかに熱量が上がる話題と、義務感で話している話題の違い
3. 私が「やる」と言って、実際に着手した形跡があること
4. 私が「やりたい」と言い続けて、着手した形跡がないこと
5. 私が繰り返し避けている、または話題を変えているテーマ
6. 私が言っていることと、実際に相談してくる内容がずれている箇所（事実として）

推測が入る場合は「推測」と明記してください。会話に無いことは書かないでください。
```

ポイントは**3と4を分けて聞く**こと。人は「やりたいこと」を語るときは嘘をつくが、「実際に何に手をつけたか」の記録は嘘をつかない。願望ではなく行動を出させる。

出てきた文章は、そのまま保存する。**この時点では解釈しない。**

### Step 2：ここが抜けている工程

ほとんどの人はStep 1で終わる。詳しい自己分析が出てきて、なるほどと思って、閉じる。

だが読み返してほしい。**弱みの欄が、痛くないはずだ。**

私の場合、出てきた弱みは「作り込みすぎる」「抱え込みすぎる」「理想が高い分、自分を追い込む」だった。全部、弱みの形をした自己肯定だ。強みの記述は具体例つきで長く、弱みは短く、しかも裏返せば美点になるものばかりだった。

理由ははっきりしている。**長く付き合ったAIは、あなたの自己物語に最適化されている。** あなたが自分をどう語ってきたかを学習していて、それを壊さない範囲で答える。悪気はない。設計上そうなる。

だから、別のAI（または同じAIの新しいセッション）に、こう投げる。

```
上記は、あるAIが私について書いた観察です。
このAIは私と長く話しているため、私の自己認識に寄っている可能性があります。

第三者として、次の3つをやってください。
ただし私の性格・心理・動機を断定しないでください。事実と構造だけを扱ってください。

1. この観察のうち、事実（会話に実際にあったこと）と、
   解釈（このAIが意味づけたこと）を分けてください

2. 事実の中に、互いに整合しない組み合わせがあれば、
   「AとBが同時に成り立っている」という形で並べてください。
   ※「なぜそうなのか」の説明は不要です。並べるだけにしてください

3. その組み合わせについて、本人にしか答えられない問いを3つ挙げてください
   （過去の具体的な出来事を尋ねる形で。心理を問う形にしないこと）
```

**「なぜそうなのか」を書かせないのが肝**だ。

私は最初、AIに理由まで書かせた。「あなたは〇〇への不安から△△している」という形で返ってきて、鋭いと思った。だが実際にやってみると、その説明が当たっているかどうかを考えている間に、**事実そのものを見なくなる**。診断されると、人は診断の正誤を争い始める。

理由を消して、事実を2つ並べるだけにすると、こうなる。

> 「Aを大事だと言っている。同時に、時間はBに使っている。この2つが同時に成り立っている」

説明がないから、反論する相手がいない。**自分で考えるしかなくなる。** そしてその方が、はるかに深いところまで行く。

私自身、この形で並べられた時、返す言葉がなかったものが1つあった。知らなかったことが出てきたのではない。**知っていたが、並べて見たことがなかった**だけだ。

### Step 3：AIが持っていない情報を足す

AIの記憶にないものは、自分で書く。各3〜5行でいい。**この書く行為自体に効果があることが研究で分かっている**ので、頭の中で済ませない。

1. 直近1年で、時間を忘れて没頭したことは何か。その時、具体的に何をしていたか
2. 直近1年で、金や時間を払ってでも避けたかったことは何か
3. 誰かに感謝された、「助かった」と言われた出来事を3つ
4. 他人がやっているのを見て、明確に嫉妬を感じたことは何か
5. 「これは自分の役割ではない」と感じる仕事は何か
6. 5年後、絶対にそうなっていたくない状態は何か

6番目が効く。やりたいことは言葉にしづらいが、**なりたくない状態は誰でも即答できる**。そこから逆算する方が速い。

### Step 4：選択肢を、絞らずに並べる

ここで多くの自己分析は「あなたの天職はこれです」と1つに絞ろうとする。私は逆にした。**絞らせない。**

Step 1〜3の全部を渡して、こう頼む。

```
上記すべてを踏まえ、次を出力してください。推測は推測と明記してください。

A. 実際に時間・金・感情を使った対象から逆算される価値観（自己申告ではなく行動から）3〜5個
B. 他人に感謝された事実・繰り返し成功している行動から見える強み 3個
C. 理想と現状のギャップを埋めうる選択肢を、5つ以上並べてください
   - 一つに絞らないこと
   - 「何もしない」も選択肢として必ず入れること
   - 各選択肢について: それが成立するために真である必要がある前提を1つ
D. 各選択肢について、2〜4週間でその前提を確かめられる最小の行動

順位はつけないでください。選ぶのは私です。
```

**「順位をつけないでください」の一行が効く。**

AIに順位をつけさせると、その順位が正しいかを考え始めてしまう。並んでいるだけなら、自分で見比べるしかない。そして人は、比べられる状態になって初めて選べる。

ここにも「役割としての理想」と「自分としての理想」を分けて入れておくといい。**仕事や立場としてそうあるべきだと思っていること**と、**自分としてどうしたいか**は、たいてい違う。混ぜたままだと、詰まりの正体が見えない。

### Step 5：自分で1つ選び、崩れない形で書く

並んだ選択肢から、**自分で**1つ選ぶ。理由を1行書く。「何もしない」を選んでもいい——ただし「今は決めない」も、決めたこととして書く。曖昧に終わらせないことだけが条件だ。

そして選んだ1つについて、これを書く。

- **やること**: 2〜4週間で検証すること（1文）
- **分かること**: それが真だった場合、何が分かるか
- **邪魔**: 実行を妨げる自分の内的障害（「時間がない」は障害ではない。「夜になると疲れて開かない」くらい具体的に）
- **対策**: 「もし〈その状況〉になったら、〈この代替行動〉をする」の形で書く
- 検証日を決めてカレンダーに入れる

最後の「もし〜なら〜する」の形式は、目標達成の研究で最も再現性のある手法のひとつだ。意志ではなく条件分岐で動くようにする。

### 見つかった後の話

このワークをやると、たいてい最後に「やりたいことは見えたが、どうやればいいか分からない」という壁が来る。実は自己分析より、こっちの方が詰まりやすい。

私はそこを、3段階で切り分けることにしている。

1. **すでに世の中にある**——だいたいこれ。調べれば既存のツールやサービスで解ける。この場合は素直にそれを使えばいい
2. **あるが、少し足りない**——既存のツールに設定や自動化を足せば届く
3. **無い**——その人の状況に合うものが存在しない。この場合は作るしかない

昔は3が絶望だった。「無いなら諦める」しかなかったからだ。**だが今は、その場で作れる。** 個人の業務に合わせた自動化も、専用のツールも、以前なら数ヶ月と数百万円かかったものが、規模によっては数時間で形になる。

やりたいことが見つかって終わり、ではなく、**見つかったものを実際に動かすところまでが一続きになった**——というのが、この1年でいちばん大きく変わったことだと思っている。

### この方法が私に効かなかった部分

正直に書いておく。この手順は万能じゃない。私が自分にやった時、外れた部分が3つあった。

**Step 1の出力の半分は、既に知っていることだった。** 「繰り返し戻る話題」は自分でも分かっていた。目新しさはない。

**Step 2で並んだもののうち、1つは事実で反証できた。** AIは私の時間の使い方について推測を立てたが、実際の数字を出したら間違っていた。第三者の目は万能ではなく、**外れることもある前提で使う道具**だ。

**そして残り1つは、まだ答えが出ていない。** 指摘は刺さったが、それが本当かどうかは、これから確かめるしかない。分析は答えを出す装置ではなく、確かめるべきことを絞る装置だった。

なぜこれを書くかというと、**うまくいった話だけを書く人の話は信用できない**からだ。私はこの方法を売っていない。効いた部分と外れた部分を両方書けるのは、売っていないからだ。

### やってみた人へ

これは私が自分に対して実際にやった手順で、そのまま公開している。ここまでに有料の何かは無い。

もし実際にやってみて、**Step 2で並んだ「同時に成り立っている2つ」を誰かに見てもらいたくなったら**、送ってくれれば第三者として読む。無料でやる。理由は正直に書くと、この方法が他の人にも機能するのかを知りたいから。

そのとき、上の3段階の切り分けも一緒にやる。1で解けるものは「これ使えば終わります」と言う。**そこで金を取るつもりはない。** 3にあたるもの——世の中に無くて、作らないと解けないもの——だけ、作る話をする。

**そして、分析そのものにお金をもらうことは、これから先もしない。** 理由は綺麗事じゃなくて構造の問題だ。分析でお金をもらう人は、相手に嫌がられると次が無くなる。だから無意識に優しくなる。**厳しいことを言えるのは、そこで食っていない人間だけだ。** 私が売るのは、見つかった後に作るものだけにする。

### もし送るなら、この形が助かる

自由に書いてもらっても読むが、この形だと**他の人のパターンと比べて読める**。他の人がどうだったかを返せるようになる。

```
1. Step 2で並んだ「同時に成り立っている2つ」を1文で:
2. いつものAIが褒めてきたこと:
3. 別のAIが褒めなかったこと:
4. 出てきた3つの方向:
5. 最初に検証すると決めた1つ:
6. 絶対になりたくない状態:
7. 今までに試して、やめたこと:
8. 人より上手くできると言われること:
9. 検証する日（日付を1つ決めてください）:
```

最後の9番が一番大事だ。**その日に、私から一度だけ連絡する。**「やりましたか。何が起きましたか」とだけ聞く。売り込みは付けない。何もしなかったなら、それも正直に教えてほしい。

やりたいことを見つける方法は世の中に山ほどある。**だが「見つけた後、実際どうなったか」を誰も記録していない。** 私はそれを記録したい。

自分の一番詳しい観察者が、自分の一番の同調者でもある——というのが、AIを毎日使う時代の新しい落とし穴だと思っている。抜け方は、もう一人分の目を入れるだけだ。
