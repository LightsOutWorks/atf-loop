## 1. 大量Concept — C-4を具体化する20案

C-4は「方向」であって設計ではない。同じC-4から作れる**まったく別の遊び**を、4つの軸で列挙する。

### 軸A. 指とECHOの関係（**Taste を決める最大の軸**）

| # | Concept | 触った時に起きること |
|---|---|---|
| A1 | **ばね** | 引っぱると体が伸びて指へ追従し、離すと弾む |
| A2 | **もちあげ** | つまむとぶら下がる。手足が揺れる。離すと落ちる |
| A3 | **じゃれる** | 指を獲物として追い、近づくと飛びかかる |
| A4 | **ひかえめ** | 指から逃げる。慣れてくると距離が縮まり、自分から寄る |
| A5 | あまえ | 指を掴んで離さない。引き剥がすまでくっついている |
| A6 | のる | 指の上に乗ろうとする。バランスを取る |
| A7 | けなみ | 撫でる**方向**で反応が変わる（順目は喜ぶ／逆目は嫌がる） |
| A8 | つぶれ | 移動しない。押した分だけ潰れて戻る（弾性だけ） |

### 軸B. 移動の質

### 軸D. 声

### 絞り込みの理由

- **Tasteを決めるのは軸A である。** Briefの「触ってみたい」「もっと触りたい」「気持ちいい」は、すべて**指とECHOの関係**が決める。World Prior側も同じ場所を指している——W2（触り心地は二値で、悪ければそこで終了）。
- **軸B / C / D は軸Aに従属する。** A3（じゃれる）に B3（すり足）は付かない。したがって**軸Aで振り、B/C/Dはそれぞれに整合する値を割り当てる**のが、少ない本数で最大の差を作る方法。
- **C1・C2・D4 は4本すべてに入れる。** これらはC-4というキャラクターの定義そのもの（耳が第一表情・耳が先に反応・音もキャラクター性の一部 — Brief §3-1 / §3-7）であり、**振る対象ではなく前提**。
- A5〜A8 は今回作らない。**A1〜A4 が「指とECHOの関係」として互いに最も遠い4点**だからである（追従／保持／捕食／回避）。A5はA1に、A6・A7・A8はA2・A4に吸収されうる。**落としたことを隠さない**——Human Tasteが4本とも外した場合、次に試すのはこの4案である。

## 2. 少数Prototype — 4本

**全4本が L-1〜L-10 の10 Loopすべてを持つ。** 差分は軸A（指との関係）と、それに整合する B/C/D の値。

| | 指との関係（軸A） | 移動 | 耳の既定 | 声 | ファイル |
|---|---|---|---|---|---|
| **A. ばね** | 引っぱると伸びて追従、離すと弾む | 跳ねる | やや前傾 | 高く短い×2 | `echo2-a-spring.html` |
| **B. あるく** | つまむとぶら下がる。触ると立ち止まって見上げる | **とことこ二足歩行**（常時） | 水平 | 低め・長め・震え | `echo2-b-gait.html` |
| **C. じゃれる** | **指を追い、飛びかかる** | 素早い・跳躍 | 強い前傾 | 鋭く高い×3 | `echo2-c-pounce.html` |
| **D. ひかえめ** | **指から逃げる → 慣れると寄る** | ゆっくり | **後ろ倒し** | 小さく震える×1 | `echo2-d-timid.html` |

**Dだけは「距離」が主表現**である。信頼が育つと**ECHOがこちらへ来る距離そのものが変わる**（Brief §3-4「playerとの距離」）。

### 10 Loopの実装（全4本共通）

| Loop | 操作 | 返り |
|---|---|---|
| L-1 撫でる・つつく・引っ張る | 体をなぞる / タップ / ドラッグ | 耳・目・口・体の変形 + 音（変形の仕方は4本で違う） |
| L-2 呼ぶ | 空きスペースを1回タップ | **耳が先に向く** → 来る / 耳だけ / 無視。信頼と独立心で分岐 |
| L-3 与える | 落ちている食べ物をECHOへドラッグ | 食べる / 嫌がって離れる。**好き嫌いは個体ごとに違い、与えて初めて分かる** |
| L-4 遊ぶ | 地面のボールを掴んで放り投げる | 追う → 持ち帰る / 独り占めする |
| L-5 邪魔する / 自由にさせる | 自発行動中の体をタップ＝中断 / 何もしない＝完遂 | **干渉した回数が「player待ち」か「自分でやる」かを決める** |
| L-6 助ける | はまって困っている時に体をタップ | 助かる。放置すると時間をかけて自力脱出（独立心が上がる） |
| L-7 放っておく | 何もしない | 戻った時の反応が変わる（寄ってくる / 拗ねる） |
| L-8 勝手に見つける・いたずら | — | 物を見つけて持ってくる / 壊す / ひとり遊び / 眠る。**持ってきた物は画面に残る** |
| L-9 音と声 | 全操作 | 触った音 / 喜び / 嫌がる / 移動 / 発見 / 重要イベント。**声は育ちで変わる** |
| L-10 最後のお願い | 十分関わった後、光る場所へ向けてECHOをドラッグして離す | ECHOが自分で決める（**行く / 断る / 別のことをする**） |

**数字は一切表示しない。** 変化は 表情 / 動き / 距離 / 好き嫌い / 行動頻度 / 声 / 体の大きさ・色 / 自発行動 にだけ出る（Brief §3-4）。

### キャラクター造形の Prior（2026-08-15 追加）

初版の造形は **ベビースキーマ（ローレンツ 1943）の第4条件「頭全体に対して目鼻口が低い所に位置している」を満たしていなかった**（目が頭のほぼ中央にあり、額が無かった）。日本のキャラクター文化側の World Prior を取得して修正し、**頭:胴 ≒ 1:1 の二頭身**へ作り替えた。あわせて次を4本共通で適用した。

- **原初模倣**（正高信男・ブラゼルトン）: 撫でた 0.5〜1.1 秒後に、ECHO の側から返す（見上げる / 鳴く / 寄ってくる）。**一方通行の入力→反応では愛着は立たない。**
- **立ち居振る舞いが不安定**（ゆるキャラ三か条②・みうらじゅん）: idle 中に低頻度でつまずく。
- **声のゆらぎ**（ちいかわ「うさぎ」の奇声が単独でトレンド入りした事実）: 発語ごとにピッチを ±6% 揺らし、同じ音の連打にしない。

**「人見知り → あなたにだけ甘える」は D「ひかえめ」だけに入れた**（他へ入れると4本の差が消えるため）。
根拠・観測値・交絡・未適用のもの（P4 ギャップ / P8 かわいい×理不尽）は `CHARACTER_PRIOR_JP.md`。
