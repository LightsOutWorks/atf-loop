# Living Ground — Mark Specification

Status: **シンボル確定 / ロゴタイプ未確定**
Decided: 2026-08-09（Human決定。記録は `DECISIONS.md` D-004）

---

## 1. 何を表すか

八卦の**巽（☴）**。下段の一本だけが切れている構造。

> 二層の水平構造＝安定・積層・継続。下段中央の余白＝受容・余地。
> 硬い構造の中に最小限のひらきを残すことで「生きる土台」を示す。

**意味をこれ以上足さない。**翼・風・拡散などの追加解釈を図形へ反映しない。

---

## 2. 幾何（確定）

基準ボックス **60 × 44.4**（単位は相対値。実寸ではない）

| 要素 | 値 |
|---|---|
| バー幅 | 60 |
| バー高さ（上段・中段） | 10 |
| バー高さ（下段） | **10.4**（下方向へ伸ばす） |
| 行位置 y | 0 / 17 / 34 |
| 行間 | 7 |
| 中央の切れ目 | 幅 **10**（x = 25〜35）= 全幅の 16.7% |
| 角丸 | **r = 1.5**、下段の**内側4隅のみ** |
| 外周の角 | すべて直角 |
| 色 | `#111111`（反転時 `#FFFFFF`） |

**下段だけ +4% にする理由**：分割によって光学的な重量が落ちるため。幾何学的に等しい 10/10/10 では下段が浮いて見えることを 360px レンダリングで実測確認済み。

**切れ目を広げない。**広げると「余地」ではなく「分断」に見える。

---

## 3. 小サイズ版（32px 以下・別ファイル）

`living-ground-mark-small.svg`

- 角丸を **0** にする（極小域では角丸が切れ目を食い、逆に読めなくなる）
- 行間を **7 → 8.5** に開く（基準ボックス 60 × 47）
- 下段の +4% 補正は行わない（サブピクセルとなり無効）

16px でも三段構造と中央の切れ目が判別できることを実測確認済み。

## 5. 未確定 — ロゴタイプ

書体は**未決**。ロックアップ内の文字は現在システムフォント指定であり、最終アセットではない。

候補（いずれも幾何学サンセリフ、既存案の字形に整合）:

1. **Jost\*** — SIL OFL・商用可・ライセンス risk なし。Futura 系で、広い字間でも字が散らない
2. **Poppins** — 無料。より丸く親しみやすいが、広い字間で空きすぎる
3. **Futura PT** — 原典。有料ライセンス

決定後、**必ずアウトライン化**してから最終アセットに含める（フォント依存を残さない）。

字間は現行の広めを維持してよいが、広げすぎると高級ブランド寄りになる。**シンボル単体 / 横組み / 黒地反転の3パターンで確認して決める。**

---

## 6. 使用ルール

- 縦横比を変えない
- 回転させない
- 色を替えない（黒 / 白のみ）
- 余白は最低でもバー高さ1本分（= 10）を四方に確保する
- 32px 以下では必ず小サイズ版を使う
