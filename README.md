# atf-loop — NEON RANGE(60秒射的トイ)

`index.html` 1ファイルだけで動く、ブラウザ FPS 風の射的トイです。
60 秒間、宙に浮かぶ光のオーブをできるだけ多く撃ち抜きます。
外部通信・外部ライブラリ・外部素材は一切使っていません(ルールは [CONSTRAINTS.md](CONSTRAINTS.md) 参照)。

## 遊び方

1. `index.html` をブラウザで開く(ダブルクリックで OK。サーバー不要)
2. **START** を押す(Enter / Space / 画面タップでも開始)
3. 60 秒間、照準(画面中央)にオーブを合わせて撃つ
4. TIME UP 後に **REPLAY** で何度でも再挑戦

### 操作

| 操作 | PC | スマートフォン |
|---|---|---|
| 視点移動 | マウスを動かす(矢印キー / WASD でも可) | 画面をドラッグ |
| 発射 | クリック / Space / Enter | 短くタップ |
| サウンド切替 | M キー / 左下の ♪ ボタン | 左下の ♪ ボタン |

### ルール

- 通常オーブ: **+1 点**
- 金色のコア: **+3 点**(動きが速く、数秒で別の場所へ逃げる)
- 連射は約 0.18 秒間隔まで。結果画面に命中率とベストスコアが出ます

## 動作検証

Node.js があれば、固定 6 項目のスモークテストを実行できます。

```sh
node smoke.mjs
```

検証項目: ①`index.html` の存在 ②外部参照なし ③構文エラーなし ④読み込み成功 ⑤開始操作あり ⑥再プレイ可。

## ファイル構成

- `index.html` — ゲーム本体(HTML/CSS/JS すべて内包)
- `CONSTRAINTS.md` — 最優先の制約ルール
- `smoke.mjs` — 機械検証スクリプト(Node.js 標準モジュールのみ使用)
- `devlog.md` — 開発ログ(判断・失敗・未解決事項)
