# ルーン・カデンツァ / Rune Cadenza

ファンタジー世界観のリズムゲーム。**楽曲・効果音・背景をすべてブラウザ内で生成する**単一HTMLファイル。

`index.html` をブラウザで開くだけで動く。ビルド不要・通信なし・外部アセットなし。

```
open apps/rhythm-fantasy/index.html
```

## 遊び方

画面は4つの縦の道に分かれている。落ちてきたルーンが下の判定円に重なった瞬間に、その道をタップする。

| ルーン | 名前 | キーボード |
|---|---|---|
| 焔 | IGNIS | `D` / `←` |
| 蒼 | AQUA | `F` / `↓` |
| 疾 | VENTUS | `J` / `↑` |
| 巌 | TERRA | `K` / `→` |

- **長押しルーン** — 尾を引いたルーンは押したままにする。最後まで保つと追加得点。
- **同時詠唱** — 線で結ばれた2つのルーンは2本指で同時に押す（難しいのみ）。
- **判定** — PERFECT / GREAT / GOOD / MISS。MISSで生命の灯が減り、尽きると失敗。
- **一時停止** — 右上のボタン、または `Esc`。裏画面に回ると自動で止まる。

得点は 1,000,000 点満点（精度 900,000 + 最大チェイン 100,000）。
ランクは SSS（全PERFECT）/ SS / S / A / B / C / D。

## 収録曲（3章 × 3難易度）

| 章 | 曲 | BPM | 調 | 長さ |
|---|---|---|---|---|
| I | 囁きの森 / Whispering Grove | 92 | Dマイナー | 約84秒 |
| II | 竜嶺の道 / Wyrmridge Pass | 128 | Aマイナー | 約75秒 |
| III | 星霜の玉座 / Throne of Ages | 156 | Eハーモニックマイナー | 約68秒 |

難易度は **簡単（NOVICE）/ 普通（ADEPT）/ 難しい（ARCHMAGE）** の3段階。
難易度が変えるのは、拍のグリッド・ノート密度・判定幅・落下速度・失敗しやすさ・同時押しの有無。

計測値（Lv は密度とピークNPSから自動算出）:

| 曲 | 簡単 | 普通 | 難しい |
|---|---|---|---|
| 囁きの森 | Lv4 / 89 | Lv7 / 122 | Lv8 / 149 |
| 竜嶺の道 | Lv6 / 121 | Lv8 / 162 | Lv10 / 196 |
| 星霜の玉座 | Lv7 / 124 | Lv11 / 196 | Lv13 / 256 |

## 作りの要点

**音楽** — Web Audio API のオシレータとノイズだけで合成する。音源ファイルは持たない。
ハープ（撥弦）・笛・角笛・パッド・ベース・鐘・バスドラム・スネア・ハイハット・シンバルを実装し、
リバーブのインパルス応答もその場で生成する。楽曲は和音進行・旋律フレーズ・
16分割の打楽器パターンを組み立てて作る（`buildGrove` / `buildRidge` / `buildThrone`）。

**譜面** — 手書きせず、**旋律イベントそのものから生成する**。だから必ず曲と合う。
難易度ごとに拍グリッド（4分 / 8分 / 16分）と最小間隔でふるいにかけ、音の高さを四分位でレーンへ割り当て、
旋律が上がったら右・下がったら左へ動くよう補正する。旋律が休む拍は普通・難しいで補う。

**時間** — 判定も描画も `AudioContext.currentTime` を基準にする。`requestAnimationFrame` の揺れで
ずれない。一時停止は `AudioContext.suspend()`。停止の切れ目に落ちたルーンは、失敗にも成功にも数えない
（分母から除く）。

**音ズレ調整** — 端末ごとの音の遅れを吸収するため、`設定 → タップで自動調整` で
クリック音とタップのずれの中央値（上下1/4を捨てた平均）を測って補正値にする。手動スライダーでも設定可。

**入力** — Pointer Events（非対応環境は Touch Events）でマルチタッチ対応。
2本指の同時押しを取りこぼさない。キーボードにも対応。

**描画** — Canvas 2D。背景は3場面とも手続き生成（森・尾根と竜・崩れた玉座）で、
静止部分は画面サイズが変わったときだけ別キャンバスへ描いて使い回す。

**保存** — 設定と自己最高記録は `localStorage` にのみ保存する。送信しない。

## 動作確認（2026-08-11 実測）

Chromium（Playwright / 端末 390×844・834×1112・844×390・320×568・1024×768）で以下を確認:

- 3曲 × 3難易度すべてで譜面が生成され、完全入力で 1,000,000 点・SSS・判定単位が譜面と一致する
- 入力精度25%では生命の灯が尽き、失敗（ランクF）で結果画面が出る
- 一時停止・再開で曲時刻が飛ばない。停止中に落ちたルーンは分母から除かれる
- 自己最高記録が `localStorage` に保存され、再読み込み後も表示される
- 音ズレ設定 100ms が判定時計を 0.1 秒ずらす
- 楽曲を OfflineAudioContext で30秒レンダリングし、NaN 0・クリップ 0・
  ピーク 0.82〜0.90・イントロと主部で音量に起伏があることを確認
- JavaScript エラー 0 / 外部URL参照 0（`http(s)://`・`fetch`・`<script src>`・`<link>`・`@import`・`url()` いずれも無し）

未確認: 実機 iOS / Android での音の遅れと発音の詰まり、実際の聴感。
