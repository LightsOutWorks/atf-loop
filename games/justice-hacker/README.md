# ハッカー・ライト ― ひかりをとりもどせ

なぞを解くとハッキングが成功し、ストーリーが進む謎解きアドベンチャー。
プレイヤーは正義のハッカー「ライト」となり、街のコンピューターを乗っ取った悪の組織「ナイトメア団」を倒す。

- **対象**: 小学3年生から（漢字はほぼ使わず、ひらがな・カタカナ中心）
- **問題数**: 全10問 / 5ミッション。1周およそ15〜25分
- **前提端末**: iPhone・iPad の Safari（縦向き）。PC ブラウザでも動く
- **形式**: `index.html` 1ファイルで完結。ビルド不要、`file://` で直接開いて遊べる

```
open games/justice-hacker/index.html
```

## 設計方針

### 難易度は低く、頭の柔らかさは要る

計算力や知識ではなく「見方を変えられるか」だけを問う。
言葉を逆から読む、縦に読む、上半分だけ見る、名前の中に数字を見つける——
どれも小3の知識で解けるが、素直に前から読んでいる限り解けない。

各問題に**3段階のヒント**を用意し、いつでも使える。詰まって終わることがないようにしてある。
不正解でもペナルティはなく、相棒AI「ルナ」が励ますだけ。2回間違えるとヒントボタンが光る。

### iPhone・iPad 前提の作り

- **独自の五十音キーボード**を内蔵。iOS の日本語IMEを開かずに答えを入力できる
  （`<input>` を使わないので、フォーカス時の自動ズームやキーボードのせり上がりが起きない）
- 五十音キーボードは**10列×5行**。ミッション3の暗号表とレイアウトを揃えてあり、
  表とキーボードの位置が対応して読み取りやすい
- キーボードは既定で畳んである。まず問題を読み、答えが分かったら「▲ キーボード」で開く。
  小さい画面でも問題の絵や表が隠れない（キーの高さは画面高に追従: `clamp(31px, 5.3vh, 44px)`）
- `viewport-fit=cover` + `env(safe-area-inset-*)`、ダブルタップ／ピンチ拡大の抑止、
  ラバーバンドスクロールの抑止、タップハイライト無効化
- 進行状況は `localStorage` に保存。閉じても「つづきから」で再開できる
- 効果音は WebAudio のコード生成音のみ（音声ファイルなし）。初回タップで有効化し、♪ボタンで消せる
- `prefers-reduced-motion` を尊重してアニメーションを止める

### 外部依存ゼロ

外部通信・CDN・外部画像・外部フォント・外部音声をいっさい使わない。
`grep -E "https?://|fetch\(|<script src|<link |@import|url\("` が無マッチであることを確認済み。

## 収録問題

| # | ミッション | 種類 | 問うている「見方の変え方」 |
|---|---|---|---|
| 1 | 玄関ゲート | 絵の頭文字つなぎ | 絵を「名前の音」として見る |
| 2 | 玄関ゲート | 動物の名前の中の数字 | 名前の一部を数字の読みとして見る |
| 3 | 監視カメラ | 回文の仲間はずれ | 言葉を逆から読む |
| 4 | 監視カメラ | 上半分だけの文字 | 欠けた情報を補って読む |
| 5 | データ金庫 | 光の棒を1本動かす | 記号も「動かせる部品」として見る |
| 6 | データ金庫 | 五十音表の暗号 | 数字を位置として読む |
| 7 | ファイアウォール | しりとり＋罠カード | ルール（「ん」で終わる）から逆算する |

## 検証

Playwright（Chromium）で、実際にキーボードを叩き・カードをタップして
**最初から最後まで通しでプレイする自動テスト**を通してある。確認項目:

- 全10問を正しい操作で解いてエンディングに到達すること
- JavaScript エラーがゼロであること
- 入力欄と実行ボタンがスクロールなしで画面内に収まっていること
- キーボードの開閉が動くこと
- 不正解時のフィードバックとヒント表示が出ること

検証端末: iPhone 13 (390×664) / iPad Pro 11。
併せて 320×568 / 375×555 / 428×745 でもレイアウトを実測し、
各問題の「肝となる図版」がキーボードに隠れないことを確認している。

## 位置づけ

本作は人間からの直接依頼で作った単発の作品であり、
`works/seed-*` の Browser-Toy 生成ルート（`CONSTRAINTS.md` Part II / `factory.yml`、
`DECISIONS.md` D-001 により HOLD）とは別系統。
そのためカタログ生成（`scripts/build-catalog.mjs`）やスモーク検証（`smoke.mjs`）の
対象外となる `games/` 配下に置いている。
