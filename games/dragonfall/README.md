# ドラゴンフォール（DRAGONFALL）

サバイバー系オートバトラー（自動攻撃・レベルアップで能力を選ぶ形式）を参考にした、
1ファイル完結のブラウザゲーム。`games/dragonfall/index.html` をブラウザで開けば動く。
ビルド不要、外部通信なし、外部ファイル参照なし。

プレイヤーは攻撃しない。**どこに立つか**と**何を取るか**だけを決める。

**5分の時計**が1本だけ走る。生き延びている間だけ進み、**ボス戦の間は止まる**。
5分ちょうどでラスボスのドラゴンが出て、その戦いの間は時計は `5:00` のまま動かない。

---

## 遊び方

| | PC | スマートフォン |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面のどこでもドラッグ（相対スティック） |
| カード選択 | クリック / `1` `2` `3` | タップ |
| 一時停止 | `P` / `Esc` | — |

各ステージは「時計が区切りに達する → 警告 → ボス出現 → 撃破」で進む。
撃破すると次の章へ持ち込みで進み、最大体力の35%が回復する。

| 時計 | 章 | ボス |
|---|---|---|
| 0:00 → 1:20 | 第一章 腐蝕の野 | 屍群の王 |
| 1:20 → 2:55 | 第二章 氷結の原 | 氷獄の王 |
| 2:55 → 4:30 | 第三章 雷鳴の峰 | 雷帝 |
| 4:30 → **5:00** | 最終章 竜の巣 | **終焉の竜** |

時計はサバイバル中だけ進むので、ボス戦にどれだけ手間取っても**竜は必ず5:00ちょうどに出る**。
HUDには `ボス戦 · 時計停止中` と出て、時計が止まっていることが見える。

## 操作感

「操作性が悪い」を推測で直さず、**計測してから直した**。原因は3つあり、体感を一番壊していたのは移動ではなく**照準**だった。

| 計測項目 | 修正前 | 修正後 |
|---|---|---|
| キー入力 → 最高速の90%まで | 157 ms | **75 ms** |
| キーを離す → 停止まで | 199 ms | **82 ms** |
| 親指を3px揺らしたときの誤移動 | 12 px/s | **0** |
| スティックが最高速に届く距離 | 52 px | **34 px** |
| 敵の群れの中での刀の回転速度 | 60.4 rad/s | **3.5 rad/s** |
| 同・向きが反転した回数 | 18.7 回/s | **0 回/s** |

**1. 加速と減速を分けた。** 元は加速も減速も同じ定数（15/s）で、離してから止まるまでが遅い＝「滑る」と感じる主因。止まる方を速く（加速30 / 制動42）した。氷ステージだけは専用の定数（7 / 9）を持たせて**滑りは残した**（停止まで326ms、ステージ1の74msと明確に別物）。

**2. スティックに不感帯を入れた。** 不感帯が無いので、置いた親指の微動でキャラが歩き出していた。6pxの不感帯＋throwを34pxに短縮。さらに**台座を浮かせて**、throwを超えて引くとリング自体が親指に付いてくる（＝長くドラッグしても端で頭打ちにならない）。リングは104px→78pxに縮めた。

**3. 照準のばたつきを止めた（これが最大）。** 毎フレーム「一番近い敵」を選び直していたため、群れの中では刀が毎秒10回転近く暴れていた。**一度捕捉した敵は、死ぬ・範囲外に出る・明確に近い敵が現れる（30%以上近い、僅差では乗り換えない）まで持ち続ける**ようにし、旋回速度も14 rad/sで頭打ちにした。

バランスが変わっていないことも確認済み：`verify.mjs` を8回連続で全項目PASS、時計40秒時点の討伐数は変化なし、旧ビルドとの生存時間比較（交互実行・各n=10）も分布が重なった。

## 日本語化

画面に出る文字を**すべて日本語**にした。残しているのは `WASD` と `P`（キーの名前そのもの）と
`Lv`、それに数字だけ。

翻訳しただけでは崩れる箇所があったので、そこも直した。

- **字間。** 英大文字前提で `letter-spacing` を .16〜.24em まで開けていた。日本語では文字が
  ばらけるだけなので .02〜.1em に詰めた。
- **折り返し。** 日本語はどの文字位置でも折り返せるため、文末に「る。」のような1〜2文字の
  孤立行が出ていた。タイトル画面の説明文を5行の短文に割り、`word-break:auto-phrase` を足し、
  トースト下段は `nowrap` をやめて折り返すようにした。
- **リザルト表。** 英語版はラベルを半角スペースで埋めて桁を揃えていた。全角ラベルでは
  この方法が成立しないので、**2列のCSS Grid**に作り替えてレイアウトで揃えている。
- **ステージ一覧。** 行ごとに独立したgridだったので列が揃っていなかった。`display:contents`
  で1つのgridにまとめた。

用語は次のように統一した。

| 英語 | 日本語 |
|---|---|
| STAGE 1〜3 / FINAL | 第一章〜第三章 / 最終章 |
| ROTTING FIELDS / FROZEN EXPANSE / THUNDER PEAK / DRAGON'S ROOST | 腐蝕の野 / 氷結の原 / 雷鳴の峰 / 竜の巣 |
| THE HORDE KING / THE FROST MONARCH / THE STORM LORD / THE DRAGON | 屍群の王 / 氷獄の王 / 雷帝 / 終焉の竜 |
| KATANA / SCROLL / AWAKENED | 日本刀 / 巻物 / 覚醒 |
| COMMON / FROSTBOUND / STORMFORGED / ULTIMATE | 通常 / 氷結 / 雷鍛 / 究極 |
| SURVIVE / BOSS · CLOCK HELD / KILLS / HP | 生存 / ボス戦 · 時計停止中 / 討伐 / 体力 |

**やり残しを防ぐために検証を1項目足した（項目19）。** 走行を1本まるごと回して、
DOMに書き込まれた文字とCanvasに描かれた文字を**全部記録し**、`Lv` 以外のラテン文字が
1つでも混じっていたら落ちる。実際にこれで `最大HP+28` の取りこぼしを検出し、`最大体力+28` に直した。
最新の実行では51,511個の表示文字列を確認している。

描画コストへの影響も測った（交互実行・各7回・フレーム時間の中央値）。日本語版 53.0ms /
英語版 52.0ms。ただし英語版の測定値自体が30.4〜54.7msとばらついており、**この差は誤差の範囲**で、
日本語化による重さは検出できていない。

## ステージとボスの設計

ボスはHPが多いだけの敵にしない。**それぞれ別のことを要求する**。

### 第一章 — 腐蝕の野 ／ ボス: 屍群の王（ゾンビ大量）

腐った平原。ウォーカー・ランナー・ロットハウンド（ゾンビ犬）・ブローター（倒すと爆発して小型ゾンビ3体に割れる）。

ボスは「**群れそのもの**」。中心から320px以内に生きている雑魚がいるほど
被ダメージが減る（1体あたり2.8%減、最大60%減）。HUDに `屍の護り xx% · 周囲 n 体` と出る。
そしてボスは5秒ごとに雑魚を円状に召喚し続ける。

つまり **ボスだけを殴っても削れない。群れを間引いてから殴る**。これが第一ステージの学習内容になる。
体力50%以下で激昂し、召喚間隔が縮み、ブローターを混ぜ、突進が速くなる。

### 第二章 — 氷結の原 ／ ボス: 氷獄の王（氷）

氷原。**床が滑る**（この章だけ加速度と制動が 30 / 42 → 7 / 9 になり、止まりたい位置で止まれない）。
シェイドは通った跡に減速フィールドを残し、シャードリングは氷弾を撃って距離を取る。

ボスの主軸は「**隙間のある拡大リング**」。安全な角度が1か所だけ空いた輪が広がってくるので、
滑る床の上でその隙間まで移動する必要がある。加えて地面の氷柱予兆と、5〜7発の遅延着弾。
体力50%以下で吹雪（常時減速＋螺旋弾幕）に入る。

要求されるのは**先読みした移動**。反応してから動いたのでは滑って間に合わない。

### 第三章 — 雷鳴の峰 ／ ボス: 雷帝（サンダー）

雷の山頂。ウィスプ（高速でジグザグ）、ハウンド（溜めてから突進）、センチネル（3方向弾）。

ボスの攻撃は**すべて事前に図形で予告される**。着弾円、3本の扇状ビーム、テレポート後の全方位弾。
体力50%以下で4本の避雷塔を設置し、**塔同士を結ぶ線に雷が走る**ので、
安全地帯が四角形の辺で分断される。

要求されるのは**予告の読解**。ランダムな理不尽はひとつも置いていない。

### 最終章 — 竜の巣 ／ ボス: 終焉の竜（ラスボス）

竜の巣。ドラゴンは3フェーズで、**前の3ステージを引用して戻してくる**。

| 形態 | 体力 | 内容 |
|---|---|---|
| 第一形態 · 炎 | 100–66% | 7方向のファイアボール、掃射ブレス、地面に残る炎 |
| 第二形態 · 氷と雷 | 66–33% | 氷ブレス（被弾で減速）＋ 雷の着弾予告、各章の精鋭を召喚 |
| 第三形態 · 空が落ちてくる | 33–0% | 隕石雨（安全地帯あり）、隙間つきリング、急降下突進、百鬼夜行の召喚 |

第二形態で**妖怪（鬼・鬼火）を呼び始め**、第三形態では**鬼の面をかぶる**（見た目が変わる）。
天狗と鬼火の行列を呼ぶので、刀の2倍ダメージがそのままラスボス戦で効く。

形態移行時は1.3秒だけ無敵になり `鱗が光っている · ダメージ無効` と表示される。
全フェーズ共通で7.5秒ごとに「風圧」があり、プレイヤーを外側に吹き飛ばして
元いた位置に炎を残す（＝立ち位置を強制的に崩される）。

## 見た目

主人公も敵も、**すべてCanvasの図形で描いている**。画像ファイルは一枚も使っていない。

### 主人公

指定のイメージ（くるくるの黒髪・青い柄シャツと短パン・裸足・満面の笑み）に合わせて描き起こした。
参考にした写真そのものはリポジトリに取り込んでいない。

走ると脚が交互に出て体が上下し、止まると呼吸ぶんだけ揺れる。刀は常に狙っている方向へ構え、
斬るタイミングで実際に振り抜く。覚醒すると刃が伸びてピンクに光る。
足元に薄いリングを敷いてあるのは、敵200体の中で自分を見失わないため。

### 敵

14種すべてを別々のシルエットで描き直した。**まず輪郭で見分けがつくこと**を優先し、
細部はその次に置いている。

| 系統 | 見た目 |
|---|---|
| ゾンビ | 破れたシャツ、前に伸ばした両腕、傾いた頭、開いた顎、光る目 |
| ゾンビ犬 / 雷犬 | 四足のギャロップ、あばら、突き出た鼻面、牙 |
| 毒虫 | 6本脚、鞘翅の合わせ目、触角、**複眼と大顎のある顔** |
| 氷 | シェイドは襤褸のフード、シャードリングは結晶の群れ、ブルートは氷塊の巨体 |
| 雷 | ウィスプは尾を引く火花、センチネルは**こちらを追う目**と周回リング |
| 妖怪 | 鬼火は顔のある炎、天狗は羽と長鼻の面、鬼は角・牙・睨み |
| 鉄鵙（てつもず） | 鉄の鏃と尾翼、赤い眼光。射出前はマーカーが点滅する |

向きの扱いは2通りに分けた。**人型は上を向いたまま左右反転**し、**飛ぶもの・狙うものだけ回転**する。
全部回転させると群れがただのノイズになる。

### 描画コスト

敵1体あたり約25回の描画命令は、190体上限では重すぎた（実測: 25.4ms → 32.0ms/frame）。
各タイプのアニメーションを**ループ可能な1つの位相**に揃えたうえで、
6フレームぶんをオフスクリーンに焼いて転送する方式にした。
あわせて画面外の敵・宝石・巻物・敵弾を描画から外し、スプライトの余白も詰めた。

最終的な実測（headless Chromium・ソフトウェア描画・150体を全部画面内に置いた最悪条件、
フレーム時間の中央値・5回交互測定）:

| | frame time |
|---|---|
| 旧・簡易描画 | 25.7 ms |
| 新・全種描き直し + スプライト化 | 29.0 ms（+12.8%） |
| （参考）スプライト化なしの新描画 | 37.0 ms |

実プレイでは敵が画面外にも散るため、画面外カリングのぶんだけこれより軽くなる。

## 大量発生イベント

一定間隔で、名前つきの大量発生が起きる。画面に見出しが出て、四方から一斉に湧く。
どのイベントも巻物を2本落とす。

| イベント | 内容 |
|---|---|
| **ゾンビ大量発生** | ウォーカー・ランナー・ブローターが一斉に湧く |
| **屍犬の群れ** | ゾンビ犬の大量発生。速い個体だけの群れ |
| **毒蟲の大発生** | 毒虫の大量発生。**触れると毒**になる |
| **百鬼夜行** | 妖怪の行列（刀の出番） |
| **鉄鵙の斉射** | 鉄鵙の一斉射出 |

出るイベントの種類は章ごとに違う。

### 毒（虫）

**毒蟲**は顔のある甲虫で、接触すると**毒**になる。毒は5秒間、
**無敵時間を無視して**毎秒5.5ダメージを削り続ける。画面が緑にかぶる。
再接触では重ならず、持続時間がリセットされる。

### 鉄鵙（てつもず）

画面外から射出される巨大な鉄の追尾弾。まず現在地でマーカーが点滅し（回避猶予）、
そのあと飛行を開始する。追尾は弱い（毎秒約1.05ラジアン）ので、走り続ければ振り切れる。
接触または寿命で爆発する。撃ち落とすこともできる。

> 参考にしたのは「画面外から飛来して追尾する巨大弾」という古典的なアクション要素であり、
> 特定作品のキャラクターの名称・造形は使っていない（`CONSTRAINTS.md` Part I §1 第三者の権利）。

### 妖怪

刀の存在理由が妖怪である。妖怪には**刀のダメージが2倍**入る。

| 妖怪 | 挙動 |
|---|---|
| **鬼火** | 蛇行して迫る。倒すと2体に分裂する |
| **天狗** | 翼で高速接近し、溜めてから突進する |
| **鬼** | 巨体・高体力・高ダメージ。押し切られる |

## 刀と巻物

**日本刀**は最初から持っている唯一の武器で、**レベルアップのカードには一切出ない**。
強化手段は**巻物だけ**である。

- 巻物は敵から落ちる（通常5% / 妖怪10% / 精鋭40%）。大量発生イベントごとに2本が確定で落ちる。
- **巻物16個ごとに刀のレベルが1上がる。** HUDに `日本刀 Lv3 [7/16]` と出る。
- 妖怪に対しては常に**2倍**のダメージ。

### レベル5を超えると最強の武器になる

**レベル6（＝巻物80個）で刀が覚醒する。** `刀が覚醒した` と出て、HUDは `日本刀 覚醒` に変わる。

| | レベル1〜5 | **レベル6（覚醒）** |
|---|---|---|
| 攻撃範囲 | 前方の弧（Lv3で2方向、Lv5で3方向） | **半径300の全周（360°）** |
| ダメージ | 26 → 130 | **340**（妖怪には680） |
| 間隔 | 0.95 → 0.67秒 | **0.62秒** |
| その他 | — | 斬るたびに衝撃波 |

巻物の落下率は、**80個が走行の最後の3分の1で貯まる**ように調整してある。実測では
時計4:00（5:00中）あたりで覚醒する。最強の武器は最後に来る。

## アイテム：一番強いものを最後に

アイテムはティア制で、**そのステージに到達しないと選択肢に現れない**。

| 等級 | 解禁 | 武器 | 装備（パッシブ） |
|---|---|---|---|
| 1 通常 | 第一章 | 剣閃 / 骨片 / 炎の珠 | 生命力 / 疾風の靴 / 引き寄せの石 |
| 2 氷結 | 第二章 | 氷結波 / 氷柱の雨 | 氷の心臓 / 鉄の皮膚 |
| 3 雷鍛 | 第三章 | 連鎖雷 / 雷の領域 | 力の増幅 / 分裂核 |
| 4 **究極** | **最終章のみ** | **竜牙** | **古代の核** |

日本刀はこの表の外にある。どの等級にも属さず、カードには出ない。

最終章に入った直後、通常のレベルアップとは別に
`竜の宝の山が開く / 最強を選べ` の専用選択が一度だけ開き、
**竜牙と古代の核がそこで初めて出る**。等級4は金枠で表示される。

- **竜牙** — 追尾する竜火の槍を複数発射。着弾で爆発。Lv3以上では1回おきに前方へブレスも吐く。
- **古代の核** — ダメージ+45% / 待ち時間-25% / 弾+1 / 移動+12% / 毎秒2.5回復。

等級4は武器・装備の所持上限（各4）を無視して取れる。上限で最強装備を逃す事故が起きないようにしてある。

## 検証

```bash
node games/dragonfall/verify.mjs
```

最小限のDOMシムの上で**実際のインラインスクリプトを実行**し、ソース文字列ではなく
ゲーム状態に対して19項目を検証する。

- 起動、外部参照なし、30フレームの実行
- 自動攻撃が実際に敵を倒すか
- 第一章で等級2以上が出ないこと、および**刀がカードに出ないこと**
- ゾンビボスの「屍の護り」が実際に効いているか
- 章の連鎖 horde → frost → storm → dragon と、**各ボスの出現時刻**（竜がちょうど5:00）
- 等級4が最終章にしか出ないこと
- 竜が3形態を通過すること
- **巻物16個ごとの刀レベルアップ**と、**レベル6の覚醒が実際に強いこと**（Lv5比1.5倍超）
- **妖怪への2倍ダメージ**
- **毒の付与と、毒が実際に削った量**
- **5種の大量発生イベントがそれぞれの群れを湧かせること**
- **時計がサバイバル中だけ進み、ボス戦で止まること**
- **通常ダメージでボスを倒すとステージがクリアされること**（回帰テスト）
- リプレイでの初期化（時計・巻物・刀レベル・毒を含む）
- **プレイヤーが読む文字列がすべて日本語であること**（項目19）

全項目PASS。25回連続で安定を確認した（日本語化後は19項目で8回連続）。

### 検証中に見つけて直した実バグ

- スポーン距離630pxに対し敵速度46px/sで、敵がほぼプレイヤーに到達していなかった。
- オートエイムが常に最も近い雑魚を選ぶため、群れを連れたボスが一度も撃たれていなかった。
- **通常ダメージでボスの体力を0にすると `killEnemy` が先に `dead` を立て、`defeatBoss()` が
  呼ばれず、ボス不在の boss フェーズで走行が無限に固まった。** `killEnemy` からボスを
  `defeatBoss()` へ回して修正し、項目18を回帰テストとして追加した。
- 毒の検証がレベルアップの回復と衝突して稀に落ちていた。体力の増減ではなく**毒が削った量そのもの**を
  計測するよう検証側を直した（検証をゆるめたのではなく、計測対象を正しくした）。

本作は `works/seed-*` のBrowser-Toy生成ルートの成果物ではないため、
`smoke.mjs`（`CONSTRAINTS.md` Part II の60秒トイ契約）は本作の契約ではなく、流用していない。
ただし「検証をゆるめて見かけ上通すことを禁じる」という部分（Part I §6）は本作にも当てはまる。

## 現状わかっていること・わかっていないこと

**実測済み**

- Chromium（デスクトップ960×640 / 390×844 / 360×640）で描画・入力ともに例外なし、横スクロールなし。
- ヘッドレスの簡易ボットで計測したステージ1ボスの撃破時間は中央値およそ37秒。
- ドラゴンは同条件で30秒に約63%削れる（撃破まで概算50秒前後）。
- 巻物の実測ペース: 時計1:40で刀Lv3、3:00でLv4、3:20でLv5、**4:00でLv6（覚醒）**、
  5:00終了時点で巻物128個。
- 操作の応答（「操作感」の表）は実際にゲームを走らせて `speed` / `aim` をサンプリングして計測した。
  数値の出どころは推測ではない。
- 日本語化後、タイトル・レベルアップ・クリア・ゲームオーバー・勝利の全画面を
  960×640 / 390×844 / 360×640 で描画し、はみ出し・文字切れ・横スクロールが無いことを確認した。
  カードは**最長の説明文3枚を同時に入れた最悪条件**でも360×640に収まる。

**未検証**

- 実機のタッチ操作（ドラッグスティック）は実端末で試していない。Chromiumのタッチエミュレーションのみ。
  **応答の数値は改善したが、実機の指で「スムーズになった」と感じるかは未測定。**
- 難易度は簡易ボット（脅威を見ず円を描くだけ）を基準に調整しており、人間のプレイでの体感は未測定。
- 覚醒した刀（全周340ダメージ）が終盤を簡単にしすぎていないかは、人間のプレイでは未確認。
- 描画コストの実測はソフトウェア描画のheadless Chromiumでの相対比較であり、GPUのある実機での
  絶対フレームレートは測っていない。
- 敵の最大同時数は190で上限を設けているが、低スペック端末でのフレームレートは測っていない。
- スプライトは表示密度（devicePixelRatio、上限2）で焼いており、極端に高精細な端末では
  拡大による甘さが出る可能性がある。実機では未確認。
- **日本語のフォントは端末任せ**（`sans-serif` のみ指定、外部フォントは読み込まない）。
  検証環境に入っていた日本語対応フォントは中国語系のため、句読点の字形など細部は
  実際の日本語環境と異なる。字数・折り返し・はみ出しは確認できているが、**字形は未確認**。
