# DRAGONFALL

サバイバー系オートバトラー（自動攻撃・レベルアップで能力を選ぶ形式）を参考にした、
1ファイル完結のブラウザゲーム。`games/dragonfall/index.html` をブラウザで開けば動く。
ビルド不要、外部通信なし、外部ファイル参照なし。

プレイヤーは攻撃しない。**どこに立つか**と**何を取るか**だけを決める。

---

## 遊び方

| | PC | スマートフォン |
|---|---|---|
| 移動 | WASD / 矢印キー | 画面のどこでもドラッグ（相対スティック） |
| カード選択 | クリック / `1` `2` `3` | タップ |
| 一時停止 | `P` / `Esc` | — |

各ステージは「一定時間を生き延びる → WARNING → ボス出現 → 撃破」で進む。
撃破すると次のステージへ持ち込みで進み、最大HPの35%が回復する。

---

## ステージとボスの設計

ボスはHPが多いだけの敵にしない。**それぞれ別のことを要求する**。

### STAGE 1 — ROTTING FIELDS ／ ボス: THE HORDE KING（ゾンビ大量）

腐った平原。ウォーカー・ランナー・ブローター（倒すと爆発して小型ゾンビ3体に割れる）。

ボスは「**群れそのもの**」。中心から320px以内に生きている雑魚がいるほど
被ダメージが減る（1体あたり2.8%減、最大60%減）。HUDに `HORDE ARMOUR xx% · n STANDING` と出る。
そしてボスは5秒ごとに雑魚を円状に召喚し続ける。

つまり **ボスだけを殴っても削れない。群れを間引いてから殴る**。これが第一ステージの学習内容になる。
HP50%以下で激昂し、召喚間隔が縮み、ブローターを混ぜ、突進が速くなる。

### STAGE 2 — FROZEN EXPANSE ／ ボス: THE FROST MONARCH（氷）

氷原。**床が滑る**（このステージだけ加速度が 15.0 → 4.4 になり、止まりたい位置で止まれない）。
シェイドは通った跡に減速フィールドを残し、シャードリングは氷弾を撃って距離を取る。

ボスの主軸は「**隙間のある拡大リング**」。安全な角度が1か所だけ空いた輪が広がってくるので、
滑る床の上でその隙間まで移動する必要がある。加えて地面の氷柱予兆と、5〜7発の遅延着弾。
HP50%以下でブリザード（常時減速＋螺旋弾幕）に入る。

要求されるのは**先読みした移動**。反応してから動いたのでは滑って間に合わない。

### STAGE 3 — THUNDER PEAK ／ ボス: THE STORM LORD（サンダー）

雷の山頂。ウィスプ（高速でジグザグ）、ハウンド（溜めてから突進）、センチネル（3方向弾）。

ボスの攻撃は**すべて事前に図形で予告される**。着弾円、3本の扇状ビーム、テレポート後の全方位弾。
HP50%以下で4本のパイロンを設置し、**パイロン同士を結ぶ線に雷が走る**ので、
安全地帯が四角形の辺で分断される。

要求されるのは**予告の読解**。ランダムな理不尽はひとつも置いていない。

### FINAL — DRAGON'S ROOST ／ ボス: THE DRAGON（ラスボス）

竜の巣。ドラゴンは3フェーズで、**前の3ステージを引用して戻してくる**。

| フェーズ | HP | 内容 |
|---|---|---|
| I · FIRE | 100–66% | 7方向のファイアボール、掃射ブレス、地面に残る炎 |
| II · FROST AND LIGHTNING | 66–33% | 氷ブレス（被弾で減速）＋ 雷の着弾予告、各ステージの精鋭を召喚 |
| III · THE SKY FALLS | 33–0% | 隕石雨（安全地帯あり）、隙間つきリング、急降下突進 |

フェーズ移行時は1.3秒だけ無敵になり `SCALES GLOW · DAMAGE ABSORBED` と表示される。
全フェーズ共通で7.5秒ごとに「風圧」があり、プレイヤーを外側に吹き飛ばして
元いた位置に炎を残す（＝立ち位置を強制的に崩される）。

## アイテム：一番強いものを最後に

アイテムはティア制で、**そのステージに到達しないと選択肢に現れない**。

| ティア | 解禁 | 武器 | 遺物（パッシブ） |
|---|---|---|---|
| 1 COMMON | STAGE 1 | BLADE ARC / BONE SHARD / CINDER ORB | VITALITY / SWIFT BOOTS / LODESTONE |
| 2 FROSTBOUND | STAGE 2 | FROST NOVA / ICICLE VOLLEY | FROZEN HEART / THICK HIDE |
| 3 STORMFORGED | STAGE 3 | CHAIN BOLT / STORM FIELD | OVERCHARGE / SPLIT CORE |
| 4 **ULTIMATE** | **FINAL のみ** | **DRAGONFANG** | **ANCIENT CORE** |

最終ステージに入った直後、通常のレベルアップとは別に
`THE HOARD OPENS / TAKE THE ULTIMATE` の専用選択が一度だけ開き、
**DRAGONFANG と ANCIENT CORE がそこで初めて出る**。ティア4は金枠で表示される。

- **DRAGONFANG** — 追尾する竜火の槍を複数発射。着弾で爆発。Lv3以上では1回おきに前方へブレスも吐く。
- **ANCIENT CORE** — ダメージ+45% / クールダウン-25% / 弾+1 / 移動+12% / 毎秒2.5回復。

ティア4は武器・遺物の所持上限（各4）を無視して取れる。上限で最強装備を逃す事故が起きないようにしてある。

## 検証

```bash
node games/dragonfall/verify.mjs
```

最小限のDOMシムの上で**実際のインラインスクリプトを実行**し、ソース文字列ではなく
ゲーム状態に対して12項目を検証する（起動、外部参照なし、自動攻撃が実際に敵を倒すか、
ティア制限、ゾンビボスのHORDE ARMOURが実際に効いているか、
ステージ連鎖 horde → frost → storm → dragon、ティア4が最終ステージにしか出ないこと、
ドラゴンが3フェーズを通過すること、リプレイでの初期化）。

本作は `works/seed-*` のBrowser-Toy生成ルートの成果物ではないため、
`smoke.mjs`（`CONSTRAINTS.md` Part II の60秒トイ契約）は本作の契約ではなく、流用していない。
ただし「検証をゆるめて見かけ上通すことを禁じる」という部分（Part I §6）は本作にも当てはまる。

## 現状わかっていること・わかっていないこと

**実測済み**

- Chromium（デスクトップ960×640 / 390×844 / 360×640）で描画・入力ともに例外なし、横スクロールなし。
- ヘッドレスの簡易ボットで計測したステージ1ボスの撃破時間は中央値およそ37秒。
- ドラゴンは同条件で30秒に約63%削れる（撃破まで概算50秒前後）。

**未検証**

- 実機のタッチ操作（ドラッグスティック）は実端末で試していない。Chromiumのタッチエミュレーションのみ。
- 難易度は簡易ボット（脅威を見ず円を描くだけ）を基準に調整しており、人間のプレイでの体感は未測定。
- 敵の最大同時数は190で上限を設けているが、低スペック端末でのフレームレートは測っていない。
