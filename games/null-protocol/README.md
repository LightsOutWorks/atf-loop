# NULL PROTOCOL ― 亡霊のプロトコル

七年前に死んだ友人から、時限をかけたメールが届く。
暗号を解いて追ううちに、主人公は「自分が書いたコード」に行き着く。
大人向けの暗号解読アドベンチャー。

- **対象**: 大人。知識ではなく論理と観察で解ける難度に振ってある
- **分量**: 全9章・**20問**・結末3種。1周およそ60〜90分
- **前提端末**: iPhone・iPad の Safari（縦向き）。PC ブラウザでも動く
- **形式**: `index.html` 1ファイルで完結。ビルド不要、`file://` で直接開いて遊べる

```
open games/null-protocol/index.html
```

同じ engine の前作 `games/justice-hacker/`（小学生向け・勧善懲悪）の仕組みを土台に、
長編・成人向けとして作り直したもの。

## 意匠

「深夜三時の端末」の一点に寄せた。

- **地の文は明朝、機械の出力は等幅**。人間の声と機械の声を書体で分ける
- 近黒の地にアンバー一色。危険域だけ血の赤、ARGOS の声だけ冷えた青
- 角丸は 3px。走査線と周辺減光のみで、動きの演出は最小限
- 単一テーマに意図的に振り切っているため、配色はすべて明示指定。
  ホスト側の明暗どちらの地に置かれても崩れない

## 長編を支える仕組み（前作からの追加分）

| 機能 | 内容 |
|---|---|
| **資料庫** | 15点の文書を入手して、いつでも読み返せる。章をまたいだ照合を要求する問題がある（Q1・Q3・Q8・Q13・Q18 など） |
| **逆探知メーター** | 誤答 +4%、ヒント +6%、捕捉 +4%、時間切れ +15%。ゲームオーバーにはならず、結末の評価に効く |
| **鍵語ログ** | 通過した門の名を取得順に自動記録。最終問題で参照する |
| **章選択** | 到達済みの章から始め直せる。結末を選び直すのに使う |
| **分岐** | 中盤に1回、終盤に1回。終盤の3択が結末A/B/Cを決め、中盤の選択が後日談に反映される |
| **設定** | 効果音、文字送り（遅・標準・速・即） |
| **制限時間** | 1問だけ90秒。切れても進行は止まらず、逆探知が上がるだけ |

## 入力装置

スマホで解けることを最優先に、問題ごとに専用の装置を用意した。

- **五十音キーボード / アルファベットキーボード / 数字パッド** ―
  iOS の IME を開かずに入力できる。`<input>` を使わないので自動ズームもキーボードのせり上がりも起きない。
  既定では畳んであり、まず問題を読んでから `▲ KEYS` で開く
- **回転盤** ― ドラッグで shift を動かすと暗号文がその場で変換される（シーザー暗号）
- **ビット盤** ― 16進の行を流し込むと 20×8 のマスに像が浮かぶ。盤は画面上端に貼り付き、行をたどっても見え続ける
- **死角の迷路** ― 盤面と十字キーを固定域に置き、常に同時に見える。捕捉されても進入点に戻るだけ
- **モールス** ― 視覚と音の両方で提示。実際に鳴る（WebAudio のコード生成音）
- **並べ替え / 時系列復元 / 選択肢**

| JavaScript エラー | 0件 |

| 資料庫の一覧・詳細・鍵語ログ | OK |
| 各問題で実行UIが画面内に収まる | OK |

## 外部依存

外部通信・CDN・外部画像・外部フォント・外部音声をいっさい使わない。
`grep -E "https?://|fetch\(|<script src|<link |@import|url\("` が無マッチであることを確認済み。
効果音はすべて WebAudio のコード生成音。

## 表現について

- 特定の実在人物・団体・製品は登場しない。企業も人物も架空
- 暴力の描写に頼らず、対決はすべて暗号と論理で行う
- 実在する攻撃手法の手順は含まない。作中の「ハッキング」は謎解きの比喩として扱っている
