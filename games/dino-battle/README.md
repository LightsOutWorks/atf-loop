# きょうりゅうバトル アリーナ

恐竜どうしが1対1で戦うブラウザゲーム。`index.html` をブラウザで開くだけで遊べる（`file://` で可。サーバー不要）。

## 遊びかた

1. 画面をタップしてスタート
2. モードを選ぶ
   - **トーナメント** — 5体を順に倒してチャンピオンを目指す。勝つたびに体力が回復する（最低でも最大値の70%から次の試合に入る）
   - **じゆうバトル** — 自分と相手の両方を選んで1戦だけ戦う
3. 恐竜をタップして選び、下の「この きょうりゅうで たたかう！」へ
4. バトルは交互に行動する。わざを選ぶと**タイミングバー**が出るので、まん中の黄色いところで画面をタップする
   - まん中（ジャストヒット）= ダメージ1.45倍 / 緑のところ = 等倍 / 外す = 0.72倍
   - **ガード**はダメージを45%に減らし、きあいが+20たまる
   - きあいが100になると**ひっさつわざ**が撃てる
   - すばやさの差が大きいと「もういちど こうげき」が出ることがある

キーボードでも操作できる（1〜4でコマンド、スペースでタイミング）。

## 恐竜とタイプ

21種類。タイプは7すくみで、**にくしょく → きょだい → よろい → つの → すばやい → つばさ → うみ → にくしょく** の順に強い（矢印の先に強い）。相性が有利だとダメージ1.5倍、不利だと0.7倍になる。

プテラノドン・ケツァルコアトルスは翼竜、モササウルス・エラスモサウルスは海生爬虫類で、厳密には恐竜ではない。選択画面の説明文にその旨を書いている。

## つくりの制約

- 単一HTML / 外部通信ゼロ / 外部アセットなし（絵はCanvasのコード描画、効果音はWebAudioのコード生成）
- 第三者IPは不使用。恐竜名は実在の学名のみ
- PC・スマホ両対応（縦持ちでは地面の位置と配置を変える）、セーブ機能なし（localStorage不使用）
